###### Abstract

Time-frequency audio source separation is usually achieved by estimating
the short-time Fourier transform (STFT) magnitude of each source, and
then applying a phase recovery algorithm to retrieve time-domain
signals. In particular, the multiple input spectrogram inversion (MISI)
algorithm has shown good performance in several recent works. This
algorithm minimizes a quadratic reconstruction error between magnitude
spectrograms. However, this loss does not properly account for some
perceptual properties of audio, and alternative discrepancy measures
such as beta-divergences have been preferred in many settings. In this
paper, we propose to reformulate phase recovery in audio source
separation as a minimization problem involving Bregman divergences. To
optimize the resulting objective, we derive a projected gradient descent
algorithm. Experiments conducted on a speech enhancement task show that
this approach outperforms MISI for several alternative losses, which
highlights their relevance for audio source separation applications.

Keywords— Phase recovery, Bregman divergences, projected gradient
descent, audio source separation, speech enhancement.

## 1 Introduction

Audio source separation \[[1](#bib.bib1)\] consists in extracting the
underlying sources that add up to form an observable audio mixture. This
task finds applications in many areas such as speech enhancement and
recognition \[[2](#bib.bib2)\] or musical signal
processing \[[3](#bib.bib3)\]. State-of-the-art approaches for source
separation consist in using a deep neural network (DNN) or nonnegative
matrix factorization (NMF) to estimate a nonnegative mask that is
applied to a time-frequency (TF) representation of the audio mixture,
such as the short-time Fourier transform (STFT) \[[4](#bib.bib4)\].
Recent works such as \[[5](#bib.bib5), [6](#bib.bib6)\] operate in the
time domain directly, but TF approaches remain interesting since they
allow to better exploit the structure of sound \[[7](#bib.bib7)\].

Applying a nonnegative mask to the mixture’s STFT results in assigning
its phase to each isolated source. Even though this practice is common
and yields satisfactory results, it is well
established \[[8](#bib.bib8)\] that when sources overlap in the TF
domain, using the mixture’s phase induces residual interference and
artifacts in the estimates. With the advent of deep learning, magnitudes
can nowadays be estimated with a high accuracy, which outlines the need
for more advanced phase recovery algorithms \[[9](#bib.bib9)\].
Consequently, a significant research effort has been put on phase
recovery in DNN-based source separation, whether phase recovery
algorithms are applied as a post-processing \[[8](#bib.bib8)\] or
integrated within end-to-end systems for time-domain
separation \[[10](#bib.bib10), [11](#bib.bib11), [12](#bib.bib12)\].

Among the variety of phase recovery techniques, the multiple input
spectrogram inversion (MISI) algorithm \[[13](#bib.bib13)\] is
particularly popular. This iterative procedure consists in retrieving
time-domain sources from their STFT magnitudes while respecting a mixing
constraint: the estimates must add up to the mixture. This algorithm
exhibits a good performance in source separation when combined with
DNNs \[[10](#bib.bib10), [11](#bib.bib11)\]. However, MISI suffers from
one limitation. Indeed, it is derived as a solution to an optimization
problem that involves the quadratic loss, which is not the best-suited
metric for evaluating discrepancies in the TF domain. For instance, it
does not properly account for the large dynamic range of audio
signals \[[14](#bib.bib14)\].

In this work, we consider phase recovery in audio source separation as
an optimization problem involving alternative divergences which are more
appropriate for audio processing. We consider general Bregman
divergences, a family of loss functions which encompasses the
beta-divergence \[[15](#bib.bib15)\] and some of its well-known special
cases, the Kullback-Leibler (KL) and Itakura-Saito (IS) divergences.
These divergences are acknowledged for their superior performance in
audio spectral decomposition applications such as NMF-based source
separation \[[16](#bib.bib16)\]. In a previous
work \[[17](#bib.bib17)\], we addressed phase recovery with the Bregman
divergences in a single-source setting. Here, we propose to extend this
approach to a single-channel and multiple-sources framework, where the
mixture’s information can be exploited. To optimize the resulting
objective, we derive a projected gradient
algorithm \[[18](#bib.bib18)\]. We experimentally assess the potential
of our approach for a speech enhancement task. Our results show that
this method outperforms MISI for several Bregman divergences.

## 2 Related work

In this section, we present the necessary background upon which our work
builds. We describe the baseline phase recovery problem
(Section [2.1](#S2.SS1 "2.1 Phase recovery ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation")),
its extension to multiple sources
(Section [2.2](#S2.SS2 "2.2 Multiple input spectrogram inversion (MISI) ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation")),
and its formulation using the Bregman divergences
(Section [2.3](#S2.SS3 "2.3 Phase recovery with the Bregman divergence ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation")).

### 2.1 Phase recovery

Phase recovery is commonly formulated as the following problem:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\underset{\mathbf{s}\in\mathbb{R}^{L}}{\text{min}}\|\mathbf{r}-|\mathbf{A}\mathbf{s}|^{d}\|_{2}^{2},
``` |  | (1) |

where $`\mathbf{r}\in\mathbb{R}_{+}^{K}`$ are nonnegative measurements,
usually an STFT magnitude ($`d=1`$) or power ($`d=2`$) spectrogram, and
$`\mathbf{A}\in\mathbb{C}^{K\times L}`$ is the matrix that encodes the
STFT. In the seminal work \[[19](#bib.bib19)\], the authors address
problem ([1](#S2.E1 "In 2.1 Phase recovery ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation"))
with $`d=1`$. Starting from an initial guess $`\mathbf{s}^{(0)}`$, they
propose the following update rule:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbf{s}^{(t+1)}=\mathbf{A}^{\dagger}\left(\mathbf{r}\odot\frac{\mathbf{A}\mathbf{s}^{(t)}}{|\mathbf{A}\mathbf{s}^{(t)}|}\right)
``` |  | (2) |

where $`\mathbf{A}^{\dagger}`$ is the Moore-Penrose pseudo-inverse of
$`\mathbf{A}`$ defined as
$`\mathbf{A}^{\dagger}=(\mathbf{A}^{\mathsf{H}}\mathbf{A})^{.-1}\mathbf{A}^{\mathsf{H}}`$,
which encodes the inverse STFT. This iterative scheme, known as the
Griffin-Lim (GL) algorithm, is proved to converge to a critical point of
the quadratic loss in
([1](#S2.E1 "In 2.1 Phase recovery ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation")) \[[19](#bib.bib19)\],
and can also be obtained by
majorization-minimization \[[20](#bib.bib20)\] or using a gradient
descent scheme \[[17](#bib.bib17)\]. Improvements of this algorithm
notably include accelerated \[[21](#bib.bib21)\] and real-time purposed
versions \[[22](#bib.bib22)\].

### 2.2 Multiple input spectrogram inversion (MISI)

The GL algorithm has been extended to handle multiple sources in a
source separation framework \[[13](#bib.bib13)\]. Given an observed
mixture $`\mathbf{x}\in\mathbb{R}^{L}`$ of $`C`$ sources
$`\mathbf{s}_{c}\in\mathbb{R}^{L}`$, whose target nonnegative TF
measurements are $`\mathbf{r}_{c}`$, this problem can be formulated
as \[[23](#bib.bib23)\]:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\underset{\{\mathbf{s}_{c}\in\mathbb{R}^{L}\}_{c=1}^{C}}{\text{min}}\sum_{c=1}^{C}\|\mathbf{r}_{c}-|\mathbf{A}\mathbf{s}_{c}|^{d}\|_{2}^{2}\text{ s.t. }\sum_{c=1}^{C}\mathbf{s}_{c}=\mathbf{x}.
``` |  | (3) |

The multiple input spectrogram inversion (MISI) algorithm
addresses ([3](#S2.E3 "In 2.2 Multiple input spectrogram inversion (MISI) ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation"))
when $`d=1`$ and consists of the following updates:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\forall c\text{, }\mathbf{y}_{c}^{(t)}`$ | $`\displaystyle=\mathbf{A}^{\dagger}\left(\mathbf{r}\odot\frac{\mathbf{A}\mathbf{s}_{c}^{(t)}}{|\mathbf{A}\mathbf{s}_{c}^{(t)}|}\right)`$ |  | (4) |
|  | $`\displaystyle\forall c\text{, }\mathbf{s}_{c}^{(t+1)}`$ | $`\displaystyle=\mathbf{y}_{c}^{(t)}+\frac{1}{C}\left(\mathbf{x}-\sum_{i=1}^{C}\mathbf{y}_{i}^{(t)}\right)`$ |  | (5) |

In a nutshell, this algorithm consists in performing the GL
update ([2](#S2.E2 "In 2.1 Phase recovery ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation"))
for each source individually, and then distributing the resulting mixing
error onto those estimates to yield a set of signals
$`\{\mathbf{s}_{c}\}`$ that add up to the mixture. The MISI algorithm
has been introduced heuristically in \[[13](#bib.bib13)\].
In \[[23](#bib.bib23)\], it was derived using a
majorization-minimization strategy, which proved its convergence.

### 2.3 Phase recovery with the Bregman divergence

In \[[17](#bib.bib17)\], we proposed to replace the quadratic loss in
problem ([1](#S2.E1 "In 2.1 Phase recovery ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation"))
with Bregman divergences, which encompass the
beta-divergence \[[15](#bib.bib15)\] and its special cases, the KL and
IS divergences. A Bregman divergence $`\mathcal{D}_{\psi}`$ is defined
from a strictly-convex, continuously-differentiable generating function
$`\psi`$ (with derivative $`\psi^{\prime}`$) as follows:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{D}_{\psi}(\mathbf{p}\,\bm{|}\,\mathbf{q})=\sum_{k=1}^{K}\left[\psi(p_{k})-\psi(q_{k})-\psi^{\prime}(q_{k})(p_{k}-q_{k})\right].
``` |  | (6) |

Typical Bregman divergences with their generating function and
derivative can be found, e.g., in \[[17](#bib.bib17)\] (see Table 1).
Since the Bregman divergences are not symmetric in general, we
considered the following two problems, respectively termed “left” and
“right”:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\underset{\mathbf{s}\in\mathbb{R}^{L}}{\text{min}}\,\mathcal{D}_{\psi}(\mathbf{r}\,\bm{|}\,|\mathbf{A}\mathbf{s}|^{d})\text{ and }\underset{\mathbf{s}\in\mathbb{R}^{L}}{\text{min}}\,\mathcal{D}_{\psi}(|\mathbf{A}\mathbf{s}|^{d}\,\bm{|}\,\mathbf{r}).
``` |  | (7) |

We derived two algorithms for solving these, based on gradient descent
and alternating direction method of multipliers
(ADMM) \[[17](#bib.bib17)\].

## 3 Proposed method

### 3.1 Problem setting

We propose to extend our previous approach described in
Section [2.3](#S2.SS3 "2.3 Phase recovery with the Bregman divergence ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation")
to a single-channel source separation framework. Indeed, as described in
Section [2.2](#S2.SS2 "2.2 Multiple input spectrogram inversion (MISI) ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation"),
it is necessary to include the mixture information in the optimization
problem so that the estimates add up to the mixture. We replace the loss
in ([3](#S2.E3 "In 2.2 Multiple input spectrogram inversion (MISI) ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation"))
with a Bregman divergence, as
in ([7](#S2.E7 "In 2.3 Phase recovery with the Bregman divergence ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation")),
which yields the following optimization problem:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\underset{\{\mathbf{s}_{c}\in\mathbb{R}^{L}\}_{c=1}^{C}}{\text{min}}\sum_{c=1}^{C}J_{c}(\mathbf{s}_{c})\ \text{ s.t. }\sum_{c=1}^{C}\mathbf{s}_{c}=\mathbf{x},
``` |  | (8) |

where
$`J_{c}(\mathbf{s}_{c})=\mathcal{D}_{\psi}(\mathbf{r}_{c}\,\bm{|}\,|\mathbf{A}\mathbf{s}_{c}|^{d})`$
for the “right” problem and
$`J_{c}(\mathbf{s}_{c})=\mathcal{D}_{\psi}(|\mathbf{A}\mathbf{s}_{c}|^{d}\,\bm{|}\,\mathbf{r}_{c})`$
for its “left” counterpart.

### 3.2 Projected gradient descent

Similarly to \[[17](#bib.bib17)\], we propose a gradient descent
algorithm to minimize the objective defined in
([8](#S3.E8 "In 3.1 Problem setting ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation")).
The set of signals whose sum is equal to the observed mixture
$`\mathbf{x}`$, appearing in the constraint
of ([8](#S3.E8 "In 3.1 Problem setting ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation")),
is convex. As such, we may use the projected gradient
algorithm \[[18](#bib.bib18)\] which boils down to alternating the two
following updates:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\forall c\text{, }\mathbf{y}_{c}^{(t)}`$ | $`\displaystyle=\mathbf{s}_{c}^{(t)}-\mu\nabla J_{c}(\mathbf{s}_{c}^{(t)})`$ |  | (9) |
|  | $`\displaystyle\forall c\text{, }\mathbf{s}_{c}^{(t+1)}`$ | $`\displaystyle=\mathbf{y}_{c}^{(t)}+\frac{1}{C}\left(\mathbf{x}-\sum_{i=1}^{C}\mathbf{y}_{i}^{(t)}\right)`$ |  | (10) |

where $`\nabla J_{c}`$ denotes the gradient of $`J_{c}`$ with respect to
$`\mathbf{s}_{c}`$ and $`\mu>0`$ is the gradient step size. In a
nutshell, ([9](#S3.E9 "In 3.2 Projected gradient descent ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
performs a gradient descent, and, similarly
to ([5](#S2.E5 "In 2.2 Multiple input spectrogram inversion (MISI) ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation")), ([10](#S3.E10 "In 3.2 Projected gradient descent ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
projects the auxiliary variables $`\mathbf{y}_{c}`$ onto the set of
estimates whose sum is equal to the mixture.

### 3.3 Derivation of the gradient

We derive hereafter the gradient of $`J_{c}`$. Using the chain
rule \[[24](#bib.bib24)\], we have:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\nabla J_{c}(\mathbf{s}_{c})=(\nabla|\mathbf{A}\mathbf{s}_{c}|^{d})^{\mathsf{T}}\mathbf{g}_{c},
``` |  | (11) |

where $`\nabla|\mathbf{A}\mathbf{s}_{c}|^{d}`$ denotes the Jacobian of
the multivariate function
$`\mathbf{s}_{c}\to|\mathbf{A}\mathbf{s}_{c}|^{d}`$ (the Jacobian being
the extension of the gradient for multivariate functions, we may use the
same notation $`\nabla`$), and:

|  |  |  |  |
|----|----|----|----|
|  | $`\displaystyle\text{for the ``right" problem, }\mathbf{g}_{c}`$ | $`\displaystyle=\psi^{\prime\prime}(|\mathbf{A}\mathbf{s}_{c}|^{d})\odot(|\mathbf{A}\mathbf{s}_{c}|^{d}-\mathbf{r}_{c})`$ |  |
|  | $`\displaystyle\text{for the ``left" problem, }\mathbf{g}_{c}`$ | $`\displaystyle=\psi^{\prime}(|\mathbf{A}\mathbf{s}_{c}|^{d})-\psi^{\prime}(\mathbf{r}_{c})`$ |  |

where $`\psi^{\prime}`$ and $`\psi^{\prime\prime}`$ are applied
entrywise. Now, let us note $`\mathbf{A}_{r}`$ and $`\mathbf{A}_{i}`$
the real and imaginary parts of $`\mathbf{A}`$, respectively. Using
differentiation rules for element-wise matrix
operations \[[24](#bib.bib24)\] and calculations similar
to \[[17](#bib.bib17)\], we have:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\nabla|\mathbf{A}\mathbf{s}_{c}|^{d}`$ | $`\displaystyle=\nabla\left((\mathbf{A}_{r}\mathbf{s}_{c})^{2}+(\mathbf{A}_{i}\mathbf{s}_{c})^{2}\right)^{\frac{d}{2}}`$ |  | (12) |
|  |  | $`\displaystyle=d\times\text{diag}(|\mathbf{A}\mathbf{s}_{c}|^{d-2})\left(\text{diag}(\mathbf{A}_{r}\mathbf{s}_{c})\mathbf{A}_{r}+\text{diag}(\mathbf{A}_{i}\mathbf{s}_{c})\mathbf{A}_{i}\right).`$ |  |  |

We now
inject ([12](#S3.E12 "In 3.3 Derivation of the gradient ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
in ([11](#S3.E11 "In 3.3 Derivation of the gradient ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
and develop, which yields:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\nabla J_{c}(\mathbf{s}_{c})=\mathbf{A}_{r}^{\mathsf{T}}\left(d\times\text{diag}(\mathbf{A}_{r}\mathbf{s}_{c})\text{diag}(|\mathbf{A}\mathbf{s}_{c}|^{d-2})\mathbf{g}_{c}\right)+\mathbf{A}_{i}^{\mathsf{T}}\left(d\times\text{diag}(\mathbf{A}_{i}\mathbf{s}_{c})\text{diag}(|\mathbf{A}\mathbf{s}_{c}|^{d-2})\mathbf{g}_{c}\right).
``` |  | (13) |

We remark that $`\forall\mathbf{u},\mathbf{v}\in\mathbb{C}^{K}`$,
$`\text{diag}(\mathbf{u})\mathbf{v}=\mathbf{u}\odot\mathbf{v}`$, so we
further simplify this expression:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\nabla J_{c}(\mathbf{s}_{c})=\mathbf{A}_{r}^{\mathsf{T}}\left(d\times(\mathbf{A}_{r}\mathbf{s}_{c})\odot|\mathbf{A}\mathbf{s}_{c}|^{d-2}\odot\mathbf{g}_{c}\right)+\mathbf{A}_{i}^{\mathsf{T}}\left(d\times(\mathbf{A}_{i}\mathbf{s}_{c})\odot|\mathbf{A}\mathbf{s}_{c}|^{d-2}\odot\mathbf{g}_{c}\right).
``` |  | (14) |

Finally, we remark that $`\forall\mathbf{u}\in\mathbb{C}^{K}`$,
$`\Re(\mathbf{A}^{\mathsf{H}}\mathbf{u})=\mathbf{A}_{r}^{\mathsf{T}}\Re(\mathbf{u})+\mathbf{A}_{i}^{\mathsf{T}}\Im(\mathbf{u})`$,
thus we can rewrite the
gradient ([14](#S3.E14 "In 3.3 Derivation of the gradient ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
as:¹¹ 1 Note that this gradient is not defined when at least one entry
of $`\mathbf{A}\mathbf{s}_{c}`$ is null for $`d<2`$ and/or
$`\beta\leq 1`$. To alleviate this potential issue, we consider a
regularized loss using an additive small value $`\varepsilon\ll 1`$, as
detailed in \[[17](#bib.bib17)\].

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\nabla J_{c}(\mathbf{s}_{c})=d\times\Re\left(\mathbf{A}^{\mathsf{H}}((\mathbf{A}\mathbf{s}_{c})\odot|\mathbf{A}\mathbf{s}_{c}|^{d-2}\odot\mathbf{g}_{c})\right).
``` |  | (15) |

### 3.4 Implementation of the gradient update

It is common practice to use the same window for computing both the STFT
and its inverse, up to a normalization constant $`b`$, which ensures
perfect reconstruction for usual windows (e.g., Hann or Hamming) and
overlap ratios (e.g., $`50`$ or $`75`$ $`\%`$) \[[25](#bib.bib25)\]. In
such a setting, $`\mathbf{A}^{\mathsf{H}}\mathbf{A}=b\mathbf{I}`$, and
thus $`\mathbf{A}^{\dagger}=\frac{1}{b}\mathbf{A}^{\mathsf{H}}`$:
consequently, $`\mathbf{A}^{\mathsf{H}}`$ encodes the inverse STFT up to
this normalization constant.

Let us also point out that when processing audio signals, applying
$`\mathbf{A}^{\mathsf{H}}`$ returns real-valued
signals \[[17](#bib.bib17)\]. We can therefore ignore the extra real
part
in ([15](#S3.E15 "In 3.3 Derivation of the gradient ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation")).
The gradient
update ([9](#S3.E9 "In 3.2 Projected gradient descent ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
then rewrites:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\forall c\text{, }\mathbf{y}_{c}^{(t)}=\mathbf{s}_{c}^{(t)}-\tilde{\mu}d\times\left(\mathbf{A}^{\dagger}((\mathbf{A}\mathbf{s}_{c})\odot|\mathbf{A}\mathbf{s}_{c}|^{d-2}\odot\mathbf{g}_{c})\right),
``` |  | (16) |

where $`\tilde{\mu}=\mu/b`$ is the normalized step size, which we simply
term “step size” in what follows.

Remark: When considering the quadratic loss (for which the “right” and
“left” problems are equivalent) with $`d=1`$ and step size
$`\tilde{\mu}=1`$, the gradient
update ([16](#S3.E16 "In 3.4 Implementation of the gradient update ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
becomes equivalent to the MISI
update ([4](#S2.E4 "In 2.2 Multiple input spectrogram inversion (MISI) ‣ 2 Related work ‣ Phase recovery with Bregman divergences for audio source separation")).
This outlines that our method generalizes MISI, as the latter can be
seen as a particular case of the projected gradient descent algorithm.

### 3.5 Algorithm

Inputs: Measurements $`\mathbf{R}_{c}\in\mathbb{R}_{+}^{M\times N}`$,
mixture $`\mathbf{x}\in\mathbb{R}^{L}`$, step size $`\tilde{\mu}>0`$,
Bregman divergence function $`\psi`$.

1 Initialization:

2 $`\forall c`$,
$`\mathbf{s}_{c}=\text{iSTFT}(\mathbf{R}_{c}^{1/d}\odot\frac{\text{STFT}(\mathbf{x})}{|\text{STFT}(\mathbf{x})|})`$

3 while *stopping criteria not reached* do

     4 $`\forall c`$, $`\mathbf{S}_{c}=\text{STFT}(\mathbf{s}_{c})`$

     5 if *“right”* then

         6
$`\mathbf{G}_{c}=\psi^{\prime\prime}(|\mathbf{S}_{c}|^{d})\odot(|\mathbf{S}_{c}|^{d}-\mathbf{R}_{c})`$

     7 else if *“left”* then

         8
$`\mathbf{G}_{c}=\psi^{\prime}(|\mathbf{S}_{c}|^{d})-\psi^{\prime}(\mathbf{R}_{c})`$

     9 $`\forall c`$,
$`\mathbf{y}_{c}=\mathbf{s}_{c}-\tilde{\mu}d\times\text{iSTFT}(\displaystyle\mathbf{S}_{c}\odot|\mathbf{S}_{c}|^{d-2}\odot\mathbf{G}_{c})`$

     10 $`\forall c`$,
$`\mathbf{s}_{c}=\mathbf{y}_{c}+(\mathbf{x}-\sum_{i=1}^{C}\mathbf{y}_{i})/C`$

11 end while

12 Output: $`\{\mathbf{s}_{c}\}_{c=1}^{C}`$

Algorithm 1 Phase recovery with the Bregman divergence for audio source
separation: gradient descent.

The proposed algorithm consists of alternating the
updates ([16](#S3.E16 "In 3.4 Implementation of the gradient update ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
and ([10](#S3.E10 "In 3.2 Projected gradient descent ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation")).
A natural choice for obtaining initial source estimates consists in
assigning the mixture’s phase to each source’s STFT, which is known as
*amplitude masking* and is commonly employed to initialize
MISI \[[10](#bib.bib10), [11](#bib.bib11), [13](#bib.bib13)\]:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\forall c\text{, }\mathbf{s}_{c}^{(0)}=\mathbf{A}^{\dagger}\left(\mathbf{r}_{c}^{1/d}\odot\frac{\mathbf{A}\mathbf{x}}{|\mathbf{A}\mathbf{x}|}\right).
``` |  | (17) |

The STFT matrix $`\mathbf{A}`$ and its inverse are large structured
matrices that allow for efficient implementations of matrix-vector
products. In that setting, it is more customary to handle TF matrices of
size $`M\times N`$, where $`M`$ is the number of frequency channels and
$`N`$ the number of time frames, rather than vectors of size $`K=MN`$.
As such, we provide in
Algorithm [1](#algorithm1 "In 3.5 Algorithm ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation")
the pseudo-code for practical implementation of our method.

## 4 Experiments

In this section, we assess the potential of
Algorithm [1](#algorithm1 "In 3.5 Algorithm ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation")
for a speech enhancement task, that is, with $`C=2`$ and where
$`\mathbf{s}_{1}`$ and $`\mathbf{s}_{2}`$ correspond to the clean speech
and noise, respectively. Note however that this framework is applicable
to alternative separation scenarios, such as musical
instruments \[[3](#bib.bib3)\] or multiple-speakers \[[4](#bib.bib4)\]
separation. The code related to these experiments is available online.²²
2 https://github.com/magronp/bregmisi

### 4.1 Protocol

#### Data.

As acoustic material, we build a set of mixtures of clean speech and
noise. The clean speech is obtained from the VoiceBank test
set \[[26](#bib.bib26)\], from which we randomly select $`100`$
utterances. The noise signals are obtained from the DEMAND
dataset \[[27](#bib.bib27)\], from which we select noises from three
real-world environments: a living room, a bus, and a public square. For
each clean speech signal, we randomly select a noise excerpt cropped at
the same length than that of the speech signal. We then mix the two
signals at various input signal-to-noise ratios (iSNRs) ($`10`$, $`0`$,
and $`-10`$ dB). All audio excerpts are single-channel and sampled at
$`16,000`$ Hz. The STFT is computed with a $`1024`$ samples-long ($`64`$
ms) Hann window, no zero-padding, and 75$`\%`$ overlap. The dataset is
split into two subsets of $`50`$ mixtures: a *validation* set, on which
the step size is tuned (see
Section [4.2](#S4.SS2 "4.2 Influence of the step size ‣ 4 Experiments ‣ Phase recovery with Bregman divergences for audio source separation"));
and a *test* set, on which the proposed algorithm is compared to MISI.

#### Spectrogram estimation.

In realistic scenarios, the nonnegative measurements $`\mathbf{r}_{c}`$
are estimates of the magnitude or power spectrograms of the sources. To
obtain such estimates, we use Open-Unmix \[[28](#bib.bib28)\], an open
implementation of a three-layer BLSTM neural network, originally
tailored for music source separation applications. This network has been
adapted to a speech enhancement task. It was trained on our dataset,
except using different speakers and noise environments, as described
in \[[29](#bib.bib29)\]. We use the trained model available
at \[[30](#bib.bib30)\]. This network is fed with the noisy mixtures and
outputs an estimate for the clean speech and noise spectrograms, which
serve as inputs to the phase retrieval methods.

#### Compared methods.

We test the proposed projected gradient descent method described in
Algorithm [1](#algorithm1 "In 3.5 Algorithm ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation")
in a variety of settings. We consider magnitude and power measurements
($`d=1`$ or $`2`$), “right” and “left” problems, and various values of
$`\beta`$ for the divergence ($`\beta=0`$ to $`2`$ with a step of
$`0.25`$). The step size is tuned on the validation set. As comparison
baseline, we consider the MISI algorithm (which corresponds to our
algorithm with $`\beta=2`$, $`d=1`$ and $`\tilde{\mu}=1`$). Following
traditional practice with MISI \[[10](#bib.bib10), [11](#bib.bib11)\],
all algorithms are run with $`5`$ iterations.

In order to evaluate the speech enhancement quality, we compute the
signal-to-distortion ratio (SDR) between the true clean speech
$`\mathbf{s}_{1}^{\star}`$ and its estimate $`\mathbf{s}_{1}`$ (higher
is better):

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\text{SDR}(\mathbf{s}_{1}^{\star},\mathbf{s}_{1})=20\log_{10}\frac{\|\mathbf{s}_{1}^{\star}\|_{2}}{\|\mathbf{s}_{1}^{\star}-\mathbf{s}_{1}\|_{2}}.
``` |  | (18) |

For more clarity, we will present the SDR improvement (SDRi) of a method
(whether MISI or
Algorithm [1](#algorithm1 "In 3.5 Algorithm ‣ 3 Proposed method ‣ Phase recovery with Bregman divergences for audio source separation"))
over initialization.

### 4.2 Influence of the step size

![Refer to caption](2010.10255v2/val_sdri.png)

Figure 1: Average SDRi on the validation set obtained with the proposed
algorithm at various iSNRs, when $`d=1`$ (top) and $`d=2`$ (bottom). For
better readability, we set the SDRi at $`0`$ when convergence issues
occur as visually inspected, or when the SDRi is below $`0`$, as this
implies a decreasing performance over iterations, which is not
desirable.

First, we study the impact of the step size on the performance of the
proposed algorithm using the validation set. The mean SDRi on this
subset is presented in
Figure [1](#S4.F1 "Figure 1 ‣ 4.2 Influence of the step size ‣ 4 Experiments ‣ Phase recovery with Bregman divergences for audio source separation")
in the “right” setting, but similar conclusions can be drawn in the
“left” setting. For $`d=1`$, we remark that the range of possible step
sizes becomes more limited as $`\beta`$ decreases towards $`0`$ (which
corresponds to the IS divergence). Conversely, when $`d=2`$, we observe
that divergences corresponding to $`\beta`$ close to $`1`$ (i.e., the KL
divergence) allow for more flexibility when it comes to choosing an
appropriate step size.

For each setting, we pick the value of the step size that maximizes the
SDR on this subset and use it in the following experiment.

### 4.3 Comparison to other methods

![Refer to caption](2010.10255v2/test_sdri.png)

Figure 2: Average SDRi on the test set obtained with MISI and with the
proposed algorithm (in different settings) at various iSNRs.

The separation results on the test set are presented in
Figure [2](#S4.F2 "Figure 2 ‣ 4.3 Comparison to other methods ‣ 4 Experiments ‣ Phase recovery with Bregman divergences for audio source separation").
We observe that at high ($`10`$ dB) or moderate ($`0`$ dB) iSNRs, the
proposed algorithm overall outperforms MISI when $`d=2`$ and for
$`\beta\geq 1`$. We notably remark a performance peak at around
$`\beta=1.25`$ depending on the iSNR. This observation is consistent
with the findings of \[[17](#bib.bib17)\], where the gradient algorithm
using the KL divergence (i.e., $`\beta=1`$) in a similar scenario
($`d=2`$ and “left” formulation) exhibited good performance.

At low iSNR ($`-10`$ dB), the proposed method outperforms the MISI
baseline when $`d=2`$ and for the “left” problem formulation. This
behavior is somewhat reminiscent of \[[17](#bib.bib17)\]: when the
spectrograms are severly degraded (i.e., at low iSNR), the algorithm
based on the quadratic loss (here, MISI) is outperformed by algorithms
based on more suitable alternative losses. Besides, it is also
outperformed by a gradient algorithm based on the same quadratic loss
when using a fine-tuned step size. This highlights the potential
interest of phase recovery with Bregman divergences in such a scenario.

Finally, note that the performance of the proposed method strongly
depends on the speaker and the kind of noise used in the experiments
(noise-specific results can be obtained using the provided code, but we
do not detail them here due to space constraints). For instance, for
public square and bus noises, the proposed method consistently
outperforms MISI at $`10`$ dB iSNR while both methods perform similarly
at $`-10`$ dB iSNR. However, for living room noises, a different trend
is observed: in particular, the improvement of the proposed algorithm
over MISI becomes more significant at $`-10`$ dB iSNR. As a result,
further investigations are needed to identify the optimal $`\beta`$ for
a given class of signals, which should reduce this sensitivity and
improve the above results.

## 5 Conclusion

In this paper, we have addressed the problem of phase recovery with
Bregman divergences for audio source separation. We derived a projected
gradient algorithm for optimizing the resulting loss. We experimentally
observed that when the spectrograms are highly degraded, some of these
Bregman divergences induce better speech enhancement performance than
the quadratic loss, upon which the widely-used MISI algorithm builds.

In future work, we will explore other optimization schemes for
addressing this problem, such as majorization-minimization or ADMM,
which has recently been introduced for tackling a similar problem using
KL and IS divergences \[[31](#bib.bib31)\]. We will also leverage these
algorithms in a deep unfolding paradigm for end-to-end and time-domain
source separation.
````
