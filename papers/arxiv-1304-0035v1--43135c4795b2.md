###### Abstract

This paper addresses signal denoising when large-amplitude coefficients
form clusters (groups). The L1-norm and other separable sparsity models
do not capture the tendency of coefficients to cluster (group sparsity).
This work develops an algorithm, called ‘overlapping group shrinkage’
(OGS), based on the minimization of a convex cost function involving a
group-sparsity promoting penalty function. The groups are fully
overlapping so the denoising method is translation-invariant and
blocking artifacts are avoided. Based on the principle of
majorization-minimization (MM), we derive a simple iterative
minimization algorithm that reduces the cost function monotonically. A
procedure for setting the regularization parameter, based on attenuating
the noise to a specified level, is also described. The proposed approach
is illustrated on speech enhancement, wherein the OGS approach is
applied in the short-time Fourier transform (STFT) domain. The denoised
speech produced by OGS does not suffer from musical noise.

## 1 Introduction

In recent years, many algorithms based on sparsity have been developed
for signal denoising, deconvolution, restoration, and reconstruction,
etc. \[[23](#bib.bib23)\]. These algorithms often utilize nonlinear
scalar shrinkage/thresholding functions of various forms which have been
devised so as to obtain sparse representations. Examples of such
functions are the hard and soft thresholding functions
\[[22](#bib.bib22)\], and the nonnegative garrote \[[30](#bib.bib30),
[29](#bib.bib29)\]. Numerous other scalar shrinkage/thresholding
functions have been derived as MAP or MMSE estimators using various
probability models, e.g. \[[37](#bib.bib37), [25](#bib.bib25),
[46](#bib.bib46)\].

We address the problem of denoising, i.e. estimating $`x(i)`$,
$`i\in\mathcal{I}`$, from noisy observations $`y(i)`$,

|     |     |     |     |
| --- | --- | --- | --- |
|     |

       ``` math
       y(i)=x(i)+w(i),\qquad i\in\mathcal{I},
       ```                                     |     | (1) |

where the signal $`x(i)`$ is known to have a group sparse property and
$`w(i)`$ is white Gaussian noise. Here, $`\mathcal{I}`$ denotes the
domain of $`x`$, typically $`\mathcal{I}=\{0,\ \dots,\ N-1\}`$ for
one-dimensional finite-length signals. A generally effective approach
for deriving shrinkage/thresholding functions is to formulate the
optimization problem

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\mathbf{x}^{\ast}=\arg\min_{\mathbf{x}}\;\left\{F(\mathbf{x})=\frac{1}{2}\,\lVert\mathbf{y}-\mathbf{x}\rVert_{2}^{2}+{\lambda}R(\mathbf{x})\right\}
``` |  | (2) |

where $`\mathbf{x}=(x_{i},\,i\in\mathcal{I})`$ is the signal to be
determined from the observation
$`\mathbf{y}=(y_{i},\,i\in\mathcal{I})`$. In problem
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
$`\mathbf{x}`$ may represent either the coefficients of a signal (e.g.
wavelet or short-time Fourier transform coefficients) or the signal
itself, if the signal is well modeled as sparse. The penalty function
$`R(\mathbf{x})`$ (regularizer) should be chosen to promote the known
behavior of $`\mathbf{x}`$. Many of the shrinkage/thresholding functions
devised in the literature can be derived as solutions to
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
where $`R(\mathbf{x})`$ is specifically of the separable form

|     |                                              |     |     |
|-----|----------------------------------------------|-----|-----|
|     |
       ``` math
       R(\mathbf{x})=\sum_{i\in\mathcal{I}}r(x(i)).
       ```                                           |     | (3) |

For example, soft-thresholding is derived as the solution to
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
where $`r(x)=\lvert x\rvert`$, which corresponds to the lasso problem
\[[70](#bib.bib70)\] or the basis pursuit denoising problem
\[[11](#bib.bib11)\]. When $`R(\mathbf{x})`$ has the form
([3](#S1.E3 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
the variables $`x(i)`$ in
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
are decoupled, and the optimization problem
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is equivalent to a set of scalar optimization problems. Therefore, the
separable form
([3](#S1.E3 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
significantly simplifies the task of solving
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
because in this case the optimal solution is obtained by applying a
scalar shrinkage/thresholding function independently to each element
$`x(i)`$ of $`\mathbf{x}`$. From a Bayesian viewpoint, the form
([3](#S1.E3 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
models the elements $`x(i)`$ as being statistically independent.

For many natural (physically arising) signals, the variables
(signal/coefficients) $`\mathbf{x}`$ are not only sparse but also
exhibit a clustering or grouping property. For example, wavelet
coefficients generally have inter and intra-scale clustering tendencies
\[[43](#bib.bib43), [65](#bib.bib65), [69](#bib.bib69)\]. Likewise, the
clustering/grouping property is also apparent in a typical speech
spectrogram. In both cases, significant (large-amplitude) values of
$`\mathbf{x}`$ tend not to be isolated.

This paper develops a simple translation-invariant
shrinkage/thresholding algorithm that exploits the grouping/clustering
properties of the signal/coefficient vector $`\mathbf{x}`$. The
algorithm acts on $`\mathbf{x}`$ as a whole without performing
block-by-block processing, and minimizes the cost function
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
with the (non-separable) penalty function

|  |  |  |  |
|----|----|----|----|
|  |
``` math
R(\mathbf{x})=\sum_{i\in\mathcal{I}}\left[\sum_{j\in\mathcal{J}}\lvert x(i+j)\rvert^{2}\right]^{1/2},
``` |  | (4) |

where the set $`\mathcal{J}`$ defines the group. The algorithm is
derived using the majorization-minimization (MM) method
\[[28](#bib.bib28), [53](#bib.bib53)\]. The algorithm can be considered
an extension of the successive substitution algorithm for multivariate
thresholding \[[63](#bib.bib63)\] or as an extension of the FOCUSS
algorithm \[[59](#bib.bib59)\].

The penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
has been considered previously, but existing algorithms for its
minimization \[[39](#bib.bib39), [20](#bib.bib20), [27](#bib.bib27),
[3](#bib.bib3), [54](#bib.bib54), [2](#bib.bib2), [40](#bib.bib40)\] are
based on variable duplication (variable splitting, latent/auxilliary
variables, etc.). The number of additional parameters is proportional to
the overlap; hence their implementations require additional memory and
accompanying data indexing. The iterative algorithm proposed here avoids
variable duplication and can be efficiently implemented via separable
convolutions.

For the purpose of denoising, this paper also develops a conceptually
simple method to set the regularization parameter $`\lambda`$ analogous
to the ‘3$`\sigma`$’ rule. The method allows for $`\lambda`$ to be
selected so as to ensure that the noise variance is reduced to a
specified fraction of its original value. This method does not aim to
minimize the mean square error or any other measure involving the signal
to be estimated, and is thus non-Bayesian. Although conceptually simple,
the method for setting $`\lambda`$ is analytically intractable due to
the lack of explicit functional form of the estimator. However, with
appropriate pre-computation, the method can be implemented by table
look-up.

In Section
[2](#S2 "2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"),
the cost function is given and the iterative successive substitution
algorithm for its minimization is presented. In Section
[3](#S3 "3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"),
the effect of the shrinkage/thresholding algorithm on white Gaussian
noise is investigated and is used to devise a simple method for
selecting the regularization parameter $`{\lambda}`$. Section
[4](#S4 "4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
illustrates the proposed approach to signal denoising, including speech
enhancement.

### 1.1 Related work

The penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
can be considered a type of mixed norm. Mixed norms and their variants
can be used to describe non-overlapping group sparsity
\[[74](#bib.bib74), [42](#bib.bib42), [41](#bib.bib41),
[24](#bib.bib24)\] or overlapping group sparsity \[[39](#bib.bib39),
[20](#bib.bib20), [27](#bib.bib27), [38](#bib.bib38), [3](#bib.bib3),
[54](#bib.bib54), [2](#bib.bib2), [51](#bib.bib51), [73](#bib.bib73),
[12](#bib.bib12)\]. Algorithms derived using variable splitting and the
alternating direction method of multipliers (ADMM) are described in
\[[20](#bib.bib20), [27](#bib.bib27), [7](#bib.bib7)\]. These algorithms
duplicate each variable for each group of which the variable is a
member. The algorithms have guaranteed convergence, although additional
memory is required due to the variable duplication (variable splitting).
A theoretical study regarding recovery of group support is given in
\[[38](#bib.bib38)\] which uses an algorithm that is also based on
variable duplication. A more computationally efficient version of
\[[38](#bib.bib38)\] for large data sets is described in
\[[51](#bib.bib51)\] which is based on identifying active groups
(non-zero variables). The identification of non-zero groups is also
performed in \[[73](#bib.bib73)\] using an iterative process to reduce
the problem size; a dual formulation is then derived which also involves
auxiliary variables. Auxiliary and latent variables are also used in the
algorithms described in \[[54](#bib.bib54), [2](#bib.bib2),
[3](#bib.bib3), [40](#bib.bib40)\], which, like variable splitting,
calls for additional memory proportional to the extent of the overlap.
Overlapping groups are used to induce sparsity patterns in the wavelet
domain in \[[61](#bib.bib61)\] also employing variable duplication.

Several other algorithmic approaches and models have been devised to
take into account clustering or grouping behavior, such as: Markov
models \[[18](#bib.bib18), [55](#bib.bib55), [31](#bib.bib31),
[50](#bib.bib50), [21](#bib.bib21), [26](#bib.bib26), [71](#bib.bib71),
[10](#bib.bib10)\], Gaussian scale mixtures \[[56](#bib.bib56),
[33](#bib.bib33)\], neighborhood-based methods with locally adaptive
shrinkage \[[8](#bib.bib8), [66](#bib.bib66), [49](#bib.bib49)\], and
multivariate shrinkage/thresholding functions \[[63](#bib.bib63),
[64](#bib.bib64), [58](#bib.bib58), [1](#bib.bib1), [13](#bib.bib13),
[57](#bib.bib57), [62](#bib.bib62)\]. These algorithms depart somewhat
from the variational approach wherein a cost function of the form
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is minimized. For example, in many neighborhood-based and multivariate
thresholding methods, local statistics are computed for a
neighborhood/block around each coefficient, and then these statistics
are used to estimate the coefficients in the neighborhood (or the center
coefficient). In some methods, the coefficients are segmented into
non-overlapping blocks and each block is estimated as a whole; however,
in this case the processing is not translation-invariant and some
coefficient clusters may straddle multiple blocks.

It should be noted that an alternative penalty function for promoting
group sparsity is proposed in \[[52](#bib.bib52), [38](#bib.bib38)\]
(see equation (3) of \[[52](#bib.bib52)\]). Interestingly, it is
designed to promote sparse solutions for which the significant values
tend to be comprised of the unions of groups; while, as discussed in
\[[52](#bib.bib52), [38](#bib.bib38)\], the penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
promotes sparse solutions for which the significant values tend to be
comprised of the *complement* of the unions of groups. The focus of this
manuscript is an efficient algorithm for the minimization of
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
with penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
and the corresponding selection of regularization parameter $`\lambda`$.
However, the extension of this work to the penalty function of
\[[52](#bib.bib52), [38](#bib.bib38)\] is also of interest.

## 2 Overlapping group shrinkage/thresholding

### 2.1 Motivation

As shown in \[[18](#bib.bib18), [43](#bib.bib43), [69](#bib.bib69)\],
neighboring coefficients in a wavelet transform have statistical
dependencies even when they are uncorrelated. In particular, a wavelet
coefficient is more likely to be large in amplitude if the adjacent
coefficients (in scale or spatially) are large. This behavior can be
modeled using suitable non-Gaussian multivariate probability density
functions, perhaps the simplest one being

|  |  |  |  |
|----|----|----|----|
|  |
``` math
p(\mathbf{x})=\frac{C}{\sigma^{d}}\,\exp{\left(-\frac{\sqrt{d+1}}{\sigma}\lVert\mathbf{x}\rVert_{2}\right)},\quad\mathbf{x}\in\mathbb{R}^{d}
``` |  | (5) |

as utilized in \[[63](#bib.bib63)\]. If the coefficients $`\mathbf{x}`$
are observed in additive white Gaussian noise,
$`\mathbf{y}=\mathbf{x}+\mathbf{w}`$, then the MAP estimator of
$`\mathbf{x}`$ is obtained by solving
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
with $`R(\mathbf{x})=\lVert\mathbf{x}\rVert_{2}`$, the solution of which
is given by

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\hat{\mathbf{x}}=\left(1-\frac{\lambda}{\lVert\mathbf{y}\rVert}\right)_{+}\,\mathbf{y},
``` |  | (6) |

where $`(x)_{+}:=\max(x,0)`$. The function
([6](#S2.E6 "In 2.1 Motivation ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
can be considered a multivariate form of soft thresholding with
threshold $`\lambda`$.

The multivariate model and related models are convenient for estimating
small blocks/neighborhoods within a large array of coefficients;
however, when each coefficient is a member of multiple groups, then
either estimated coefficients are discarded (e.g. only the center of
each block of estimated coefficients is retained as in sliding window
processing) or the blocks are sub-sampled so that they are not
overlapping. In the first case, the result does not correspond directly
to the minimization of a cost function; whereas, in the second case, the
process is not translation-invariant and issues may arise due to blocks
not aligning with the group sparsity structure within the array. Here we
are interested in a variational approach based on fully-overlapping
groups so that the derived algorithm is translation-invariant and
blocking artifacts are avoided. The penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is clearly translation-invariant.

### 2.2 Penalty function

Assuming that $`\mathbf{x}`$ has a group sparsity (clustering) property,
to perform translation-invariant denoising, we add the $`\ell_{2}`$ norm
for each group to obtain the penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")).
The penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is convex and the cost function $`F`$ in
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is strictly convex (because
$`\lVert\mathbf{y}-\mathbf{x}\rVert_{2}^{2}`$ is strictly convex in
$`\mathbf{x}`$). The index $`i`$ is the group index, and $`j`$ is the
coefficient index within group $`i`$. Each group has the same size,
namely $`\lvert\mathcal{J}\rvert`$. In practice, $`\mathbf{x}`$ is of
finite size; hence, the sum over $`i`$ in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is a finite sum. To deal with the boundaries of $`\mathbf{x}`$, we take
$`x(i)`$ in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
as zero when $`i`$ falls outside $`\mathcal{I}`$; that is, $`x(i)=0`$
for $`i\notin\mathcal{I}`$.

For one-dimensional vectors $`\mathbf{x}`$ of length $`N`$ with group
size $`K`$, we set $`\mathcal{I}`$ in
([1](#S1.E1 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
to

|     |                                  |     |     |
|-----|----------------------------------|-----|-----|
|     |
       ``` math
       \mathcal{I}=\{0,\,\dots,\,N-1\},
       ```                               |     | (7) |

and $`\mathcal{J}`$ in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
to

|     |                                  |     |     |
|-----|----------------------------------|-----|-----|
|     |
       ``` math
       \mathcal{J}=\{0,\,\dots,\,K-1\}.
       ```                               |     | (8) |

Note that in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
the groups are fully overlapping, as per a sliding window shifted a
single sample at a time. It is possible to include a weighting $`w(j)`$
in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
as in Ref. \[[67](#bib.bib67), [68](#bib.bib68)\].

For a two-dimensional array $`\mathbf{x}`$ of size $`N_{1}\times N_{2}`$
with group size $`K_{1}\times K_{2}`$, we set $`\mathcal{I}`$ in
([1](#S1.E1 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
to

|  |  |  |
|----|----|----|
|  |
``` math
\mathcal{I}=\{(i_{1},i_{2})\,:\,0\leq i_{1}\leq N_{1}-1,\;0\leq i_{2}\leq N_{2}-1\},
``` |  |

and $`\mathcal{J}`$ in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
to

|  |  |  |
|----|----|----|
|  |
``` math
\mathcal{J}=\{(j_{1},j_{2})\,:\,0\leq j_{1}\leq K_{1}-1,\;0\leq j_{2}\leq K_{2}-1\}.
``` |  |

In the two-dimensional case, $`i+j`$ denotes
$`(i_{1}+j_{1},i_{2}+j_{2})`$. The same notation extends to higher
dimensions.

Note that minimizing
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
with
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
can only shrink the data vector $`\mathbf{y}`$ toward zero. That is, the
minimizer $`\mathbf{x}`$ of
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
will lie point-wise between zero and $`\mathbf{y}`$, i.e.
$`x(i)\in[0,y(i)]`$ for all $`i\in\mathcal{I}`$. This can be shown by
observing that the penalty function in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is a strictly increasing function of $`\lvert x(i)\rvert`$ and is
independent of the sign of each $`x(i)`$. As a result, if $`y(i)=0`$ for
some $`i\in\mathcal{I}`$, then $`x^{\ast}(i)=0`$ also, where
$`\mathbf{x}^{\ast}`$ is the minimizer of $`F`$.

An important point regarding $`R`$ in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is that it is non-differentiable. In particular, if any group of
$`\mathbf{x}`$ is equal to zero, then $`R`$ is non-differentiable at
$`\mathbf{x}`$.

### 2.3 Algorithm

To minimize the cost function $`F(\mathbf{x})`$ in
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
we use the majorization-minimization (MM) method \[[28](#bib.bib28)\].
To this end, we use the notation

|     |                                                               |     |     |
|-----|---------------------------------------------------------------|-----|-----|
|     |
       ``` math
       \mathbf{v}_{i,K}=[v(i),\,\dots,v(i+K-1)]^{t}\in\mathbb{C}^{K}
       ```                                                            |     | (9) |

to denote the $`i`$-th group of vector $`\mathbf{v}`$. Then the penalty
function in
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
can be written as

|     |                                                         |     |      |
|-----|---------------------------------------------------------|-----|------|
|     |
       ``` math
       R(\mathbf{x})=\sum_{i}\lVert\mathbf{x}_{i,K}\rVert_{2}.
       ```                                                      |     | (10) |

To majorize $`R(\mathbf{x})`$, first note that

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\frac{1}{2}\left[\frac{\lVert\mathbf{v}\rVert_{2}^{2}}{\lVert\mathbf{u}\rVert_{2}}+\lVert\mathbf{u}\rVert_{2}\right]\geq\lVert\mathbf{v}\rVert_{2}
``` |  | (11) |

for all $`\mathbf{v}`$ and $`\mathbf{u}\neq\mathbf{0}`$, with equality
when $`\mathbf{v}=\mathbf{u}`$. The inequality
([11](#S2.E11 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
can be derived from $`t^{2}+s^{2}\geq 2ts,\forall t,s\in\mathbb{R}`$ by
setting $`t=\lVert\mathbf{v}\rVert_{2}`$,
$`s=\lVert\mathbf{u}\rVert_{2}`$. Define

|  |  |  |  |
|----|----|----|----|
|  |
``` math
g(\mathbf{x},\mathbf{u})=\frac{1}{2}\sum_{i}\left[\frac{\lVert\mathbf{x}_{i,K}\rVert_{2}^{2}}{\lVert\mathbf{u}_{i,K}\rVert_{2}}+\lVert\mathbf{u}_{i,K}\rVert_{2}\right].
``` |  | (12) |

If $`\lVert\mathbf{u}_{i,K}\rVert_{2}>0`$ for all $`i\in\mathcal{I}`$,
then it follows from
([10](#S2.E10 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
and
([11](#S2.E11 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
that

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle g(\mathbf{x},\mathbf{u})`$ | $`\displaystyle\geq R(\mathbf{x})`$ |  | (13) |
|  | $`\displaystyle g(\mathbf{u},\mathbf{u})`$ | $`\displaystyle=R(\mathbf{u}),`$ |  | (14) |

for all $`\mathbf{x},\mathbf{u}`$. Therefore,
$`g(\mathbf{x},\mathbf{u})`$ is a majorizer of $`R(\mathbf{x})`$
provided that $`\mathbf{u}`$ has no groups equal to zero. Moreover, the
elements of $`\mathbf{x}`$ are decoupled in $`g(\mathbf{x},\mathbf{u})`$
and so $`g(\mathbf{x},\mathbf{u})`$ can be written as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
g(\mathbf{x},\mathbf{u})=\frac{1}{2}\sum_{i\in\mathcal{I}}r(i;\,\mathbf{u})\lvert x(i)\rvert^{2}+c
``` |  | (15) |

where

|  |  |  |  |
|----|----|----|----|
|  |
``` math
r(i;\,\mathbf{u}):=\sum_{j\in\mathcal{J}}\left[\sum_{k\in\cal J}\lvert u(i-j+k)\rvert^{2}\right]^{-1/2}
``` |  | (16) |

and $`c`$ is a constant that does not depend on $`\mathbf{x}`$. A
majorizer of the cost function $`F(\mathbf{x})`$ is now given by

|  |  |  |  |
|----|----|----|----|
|  |
``` math
G(\mathbf{x},\mathbf{u})=\frac{1}{2}\,\lVert\mathbf{y}-\mathbf{x}\rVert_{2}^{2}+{\lambda}\,g(\mathbf{x},\mathbf{u}).
``` |  | (17) |

The MM method produces the sequence $`\mathbf{x}^{(k)}`$, $`k\geq 1`$,
given by:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbf{x}^{(k+1)}`$ | $`\displaystyle=\arg\min_{\mathbf{x}}\;G(\mathbf{x},\mathbf{x}^{(k)})`$ |  | (18) |
|  |  | $`\displaystyle=\arg\min_{\mathbf{x}}\;\lVert\mathbf{y}-\mathbf{x}\rVert_{2}^{2}+{\lambda}\sum_{i\in\mathcal{I}}r(i;\,\mathbf{x}^{(k)})\,\lvert x(i)\rvert^{2}`$ |  | (19) |

where $`\mathbf{x}^{(0)}`$ is the initialization. Note that
([19](#S2.E19 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is separable in $`x(i)`$, so we can write
([19](#S2.E19 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
equivalently as

|  |  |  |  |
|----|----|----|----|
|  |
``` math
x^{(k+1)}(i)=\arg\min_{x\in\mathbb{C}}\;(y(i)-x)^{2}+{\lambda}\,r(i;\,\mathbf{x}^{(k)})\,\lvert x\rvert^{2}.
``` |  | (20) |

However, the term $`r(i;\mathbf{x}^{(k)})`$ is undefined if
$`\mathbf{x}^{(k)}_{i,K}=\mathbf{0}`$, i.e. if the $`i`$-th group is all
zero. This is a manifestation of the singularity issue which may arise
whenever a quadratic majorizer is used for a non-differentiable function
\[[28](#bib.bib28)\]. Hence, care must be taken to define an algorithm
that avoids operations involving undefined quantities.

Consider the following algorithm. Define $`\mathcal{I}^{\prime}`$ as the
subset of $`\mathcal{I}`$ where $`x^{(0)}(i)\neq 0`$,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{I}^{\prime}:=\{i\in\mathcal{I}\;:\;x^{(0)}(i)\neq 0\}.
``` |  | (21) |

Define the update equation by:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
x^{(k+1)}(i)=\begin{cases}\displaystyle\frac{y(i)}{1+{\lambda}\,r(i;\,\mathbf{x}^{(k)})},\qquad&i\in\mathcal{I}^{\prime}\\
0&i\notin\mathcal{I}^{\prime}\end{cases}
``` |  | (22) |

with initialization $`\mathbf{x}^{(0)}=\mathbf{y}`$. Note that the first
case of
([22](#S2.E22 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is the solution to
([20](#S2.E20 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")).
The iteration
([22](#S2.E22 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is the ‘overlapping group shrinkage’ (OGS) algorithm, summarized in
Table
[1](#S2.T1 "Table 1 ‣ 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
in the form of pseudo-code.

Several observations can be made.

It is clear from
([21](#S2.E21 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
and
([22](#S2.E22 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
that

|  |  |  |  |
|----|----|----|----|
|  |
``` math
x^{(0)}(i)=0\quad\implies\quad x^{(k)}(i)=0,\;\text{for all $k\geq 1$}.
``` |  | (23) |

Therefore, any values initialized to zero will equal zero throughout the
course of the algorithm. However, if $`x^{(0)}(i)=0`$, then $`y(i)=0`$
as per the initialization. Note that if $`y(i)=0`$, then the optimal
solution $`\mathbf{x}^{\ast}`$ has $`x^{\ast}(i)=0`$. Therefore

|  |  |  |  |
|----|----|----|----|
|  |
``` math
x^{(0)}(i)=0\quad\implies\quad x^{(k)}(i)=x^{\ast}(i),\;\text{for all $k\geq 1$}.
``` |  | (24) |

As a side note, if $`\mathbf{y}`$ is a noisy data vector, then it is
unlikely that $`y(i)=0`$ for any $`i\in\mathcal{I}`$.

Now consider the case where $`x^{(0)}(i)\neq 0`$. Note that if
$`x^{(k)}(i)\neq 0`$, then no groups of $`\mathbf{x}^{(k)}`$ containing
$`x^{(k)}(i)`$ are all zero. Hence $`r(i;\,\mathbf{x}^{(k)})`$ is well
defined with $`r(i;\,\mathbf{x}^{(k)})>0`$. Therefore
$`y(i)/[1+{\lambda}\,r(i;\,\mathbf{x}^{(k)})]`$ is well defined, lies
strictly between zero and $`y(i)`$, and has the same sign as $`y(i)`$.
Hence, by induction,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
x^{(0)}(i)\neq 0\quad\implies\quad x^{(k)}(i)\neq 0,\;\text{for all $k\geq 1$}.
``` |  | (25) |

Therefore, any value not initialized to zero will never equal zero in
any subsequent iteration. However, for some
$`i\in\mathcal{I}^{\prime}`$, $`x^{(k)}(i)`$ may approach zero in the
limit as $`k\rightarrow\infty`$. That is,

|  |  |  |  |
|----|----|----|----|
|  |
``` math
x^{(0)}(i)\neq 0\quad\mathchoice{\mathrel{\hbox to0.0pt{\kern 3.75pt\kern-5.27776pt$\displaystyle\not$\hss}{\implies}}}{\mathrel{\hbox to0.0pt{\kern 3.75pt\kern-5.27776pt$\textstyle\not$\hss}{\implies}}}{\mathrel{\hbox to0.0pt{\kern 2.625pt\kern-4.45831pt$\scriptstyle\not$\hss}{\implies}}}{\mathrel{\hbox to0.0pt{\kern 1.875pt\kern-3.95834pt$\scriptscriptstyle\not$\hss}{\implies}}}\quad\lim_{k\to\infty}x^{(k)}(i)\neq 0.
``` |  | (26) |

In the example in
Sect. [4.1](#S4.SS1 "4.1 One-dimensional denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"),
it will be seen that some values do go to zero as the algorithm
progresses. In practice,
([25](#S2.E25 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
may fail for some $`i\in\mathcal{I}^{\prime}`$ due to finite numerical
precision. In this case, such $`i`$ should be removed from
$`\mathcal{I}^{\prime}`$ to avoid potential ‘division-by-zero’ in
subsequent iterations.

|----|----|----|----|

The OGS algorithm produces sparse solutions by gradually reducing
non-zero values of $`\mathbf{y}`$ toward zero, rather than by
thresholding them directly to zero on any iteration, as illustrated in
Fig. [4](#S4.F4 "Figure 4 ‣ 4.1 One-dimensional denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
below.

The output of the OGS algorithm will be denoted as
$`\mathbf{x}=\ogs(\mathbf{y};\,\lambda,K)`$, where $`K`$ is the block
size. The OGS algorithm can also be applied to multidimensional data
$`\mathbf{y}`$ using the above multi-index notation, with group size
$`K=(K_{1},\dots,K_{d})`$ and where $`\mathcal{I}`$ and $`\mathcal{J}`$
are multi-indexed sets as described above.

Note that when the group size is $`K=1`$, then $`\mathcal{J}`$ in
([8](#S2.E8 "In 2.2 Penalty function ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is given by $`\mathcal{J}=\{0\}`$, and the penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is simply the $`\ell_{1}`$ norm of $`\mathbf{x}`$. In this case, the
solution is obtained by soft thresholding. When the group size $`K`$ is
greater than one, the groups overlap and every element of the solution
$`\mathbf{x}`$ depends on every element of $`\mathbf{y}`$; hence, it is
not possible to display a multivariate shrinkage function as in
\[[63](#bib.bib63)\] for the non-overlapping case.

Implementation. The quantity $`r(i;\,\mathbf{x})`$ in step (2) of the
OGS algorithm can be computed efficiently using two convolutions — one
for the inner sum and one for the outer sum. The inner sum can be
computed as the convolution of $`\lvert x(\cdot)\rvert^{2}`$ with a
‘boxcar’ of size $`\lvert\mathcal{J}\rvert`$. Denoting by $`g(\cdot)`$
the result of the inner sum, the outer sum is again a running sum or
‘boxcar’ convolution applied to $`g(\cdot)^{-1/2}`$. In the
multidimensional case, each of the two convolutions are multidimensional
but separable and hence computationally efficient.

The computational complexity of each iteration of the OGS algorithm is
of order $`KN`$, where $`K`$ is the group size and $`N`$ is the total
size of $`\mathbf{y}`$. The memory required for the algorithm is
$`2N+K`$.

Convergence. For the OGS algorithm, due to its derivation using
majorization-minimization (MM), it is guaranteed that the cost function
$`F(\mathbf{x})`$ monotonically decreases from one iteration to the
next, i.e., $`F(\mathbf{x}^{(k+1)})<F(\mathbf{x}^{(k)})`$ if
$`\mathbf{x}^{(k)}\neq\mathbf{x}^{\ast}`$. Yet, the proof of its
convergence to the unique minimizer is complicated by the ‘singularity
issue’ which arises when a quadratic function is used as a majorizer of
a non-differentiable function \[[28](#bib.bib28)\]. For the OGS problem
it is particularly relevant since, as in most sparsity-based denoising
problems, $`F(\mathbf{x})`$ will usually be non-differentiable at the
minimizer $`\mathbf{x}^{\ast}`$. Specifically, for OGS, if
$`\mathbf{x}^{\ast}`$ contains any group that is all zero, then
$`F(\mathbf{x})`$ is non-differentiable at $`\mathbf{x}^{\ast}`$.
However, several results regarding the singularity issue are given in
\[[28](#bib.bib28)\] which strongly suggest that this issue need not
hinder the reliable convergence of such algorithms in practice.

For the OGS algorithm with the initialization
$`\mathbf{x}^{(0)}=\mathbf{y}`$, the component $`\mathbf{x}^{(k)}(i)`$
will never equal zero except when $`y(i)`$ itself equals zero, as noted
above. In the OGS algorithm, the singularity issue is manifested by
$`r(i,\mathbf{x}^{(k)})`$ approaching infinity for some
$`i\in\mathcal{I}^{\prime}`$. In particular, if $`x^{\ast}(i)=0`$ for
some $`i\in\mathcal{I}^{\prime}`$, then $`r(i,\mathbf{x}^{\ast})`$ is
undefined (due to ‘division-by-zero’). For $`i\in\mathcal{I}^{\prime}`$
such that $`x^{\ast}(i)=0`$, the value of $`r(i,\mathbf{x}^{(k)})`$ goes
to infinity as the algorithm progresses, and $`x^{(k)}(i)`$ goes to
zero. Note that in the OGS algorithm, the term $`r(i,\mathbf{x}^{(k)})`$
is used only in the expression
$`y(i)/[1+{\lambda}\,r(i;\,\mathbf{x}^{(k)})]`$. Therefore, even when
$`r(i;\,\mathbf{x}^{(k)})`$ is very large, this expression is still
numerically well behaved. (When large values of opposite signs are added
to obtain small numbers, the result is not numerically reliable, but
that is not the case here.) If the algorithm is implemented in fixed
point arithmetic, then it is indeed likely that the large values of
$`r(i;\,\mathbf{x}^{(k)})`$ will lead to overflow for some
$`i\in\mathcal{I}^{\prime}`$. In this case, $`x^{(k)}(i)`$ should be set
to zero and $`i`$ should be removed from $`\mathcal{I}^{\prime}`$ for
the subsequent iterations.

We do not prove the convergence of the OGS algorithm due to the
singularity issue. However, in practice, the singularity issue does not
appear to impede the convergence of the algorithm, consistent with the
results of \[[28](#bib.bib28)\]. We have found that the empirical
asymptotic convergence behavior compares favorably with other algorithms
that have proven convergence, as illustrated in
Fig. [5](#S4.F5 "Figure 5 ‣ 4.1 One-dimensional denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals").

One approach to avoid the singularity issue is to use the differentiable
penalty function

|  |  |  |  |
|----|----|----|----|
|  |
``` math
R_{\epsilon}(\mathbf{x})=\sum_{i\in\mathcal{I}}\,\biggl[\Bigl(\sum_{j\in\mathcal{J}}|x(i+j)|^{2}\Bigr)+\epsilon\biggr]^{\frac{1}{2}}
``` |  | (27) |

where $`\epsilon`$ is a small positive value, instead of
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")).
However, as in \[[53](#bib.bib53)\], we have found it unnecessary to do
so, since we have found that the algorithm is not hindered by the
singularity issue in practice. For the regularizer
([27](#S2.E27 "In 2.3 Algorithm ‣ 2 Overlapping group shrinkage/thresholding ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
convergence of the corresponding form of OGS can be proven using the
Global Convergence Theorem (GST) \[[45](#bib.bib45), [60](#bib.bib60)\].

Proximal operator. An effective approach for solving a wide variety of
inverse problems is given by the proximal framework \[[16](#bib.bib16),
[15](#bib.bib15), [4](#bib.bib4)\]. In this approach, the solution
$`\mathbf{x}`$ to a general inverse problem (e.g. deconvolution,
interpolation, reconstruction) with penalty function $`R(\mathbf{x})`$
can be computed by solving a sequence of denoising problems each with
penalty function $`R(\mathbf{x})`$. Therefore, the efficient computation
of the solution to the denoising problem is important for the use of
proximal methods. In this context, the denoising problem, i.e.
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
is termed the *proximal operator* (or proximity operator). The OGS
algorithm is therefore an implementation of the proximal operator for
penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
and can be used in proximal algorithms for inverse problems that are
more general than denoising. As noted above, other implementations of
the proximal operator associated with overlapping group sparsity have
been given \[[2](#bib.bib2), [20](#bib.bib20), [38](#bib.bib38),
[3](#bib.bib3), [7](#bib.bib7), [12](#bib.bib12), [27](#bib.bib27),
[73](#bib.bib73), [54](#bib.bib54), [40](#bib.bib40)\]; these algorithms
are based on the duplication of variables, and hence require more memory
(proportional to the group size in the fully-overlapping case).

FOCUSS. The OGS algorithm can be considered as a type of FOCUSS
algorithm \[[34](#bib.bib34)\] that is designed to yield sparse
solutions to under-determined linear systems of equations. It was
extended to more general penalty functions (or diversity measures)
\[[60](#bib.bib60)\] and to the noisy-data case \[[59](#bib.bib59)\].
Setting $`p=1`$ and $`A=\mathbf{I}`$ in equation (13) of
\[[59](#bib.bib59)\] gives the OGS algorithm for group size $`K=1`$,
namely an iterative implementation of the soft-threshold rule. (Note,
the emphasis of FOCUSS is largely on the non-convex ($`p<1`$) case with
$`A\neq\mathbf{I}`$ and only group size $`K=1`$).

The FOCUSS algorithm was further extended to the case of multiple
measurement vectors (MMV) that share a common sparsity pattern
\[[17](#bib.bib17)\]. We note that the resulting algorithm, M-FOCUSS, is
different than OGS. In the MMV model, the location (indices) of
significant coefficients is consistent among a set of vectors; while in
the OGS problem there is no common (repeated) sparsity pattern to be
exploited.

The M-FOCUSS algorithm was later improved to account for gradual changes
in the sparsity pattern in a sequence of measurement vectors
\[[75](#bib.bib75)\]. This approach involves, in part, arranging the
sequence of measurement vectors into overlapping blocks. While both, the
algorithm of \[[75](#bib.bib75)\] and the OGS algorithm, utilize
overlapping blocks, the former algorithm utilizes overlapping blocks to
exploit a sparsity pattern (approximately) common to multiple
measurement vectors, whereas the latter does not assume any common
sparsity among blocks.

The FOCUSS algorithm was extended to mixed norms in \[[41](#bib.bib41)\]
to attain structured sparsity without overlapping groups. This approach
is extended in \[[42](#bib.bib42), [67](#bib.bib67), [68](#bib.bib68)\]
where sliding windows are used to account for overlapping groups.
However, as noted in \[[42](#bib.bib42)\], this approach does not
directly correspond to an optimization problem; hence it does not
constitute an implementation of the proximal operator.

## 3 Gaussian noise and OGS

This section addresses the problem of how to set the regularization
parameter $`\lambda`$ in
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
in a simple and direct way analogous to the ‘$`3\sigma`$ rule’. The use
of the $`3\sigma`$ rule for soft thresholding, as illustrated in
Sec. [4.1](#S4.SS1 "4.1 One-dimensional denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"),
is simple to apply because soft thresholding has a simple explicit form.
However, overlapping group shrinkage has no explicit form. Therefore,
extending the notion of the ‘$`3\sigma`$ rule’ to OGS is not straight
forward. The question addressed in the following is: how should
$`\lambda`$ be chosen so that essentially all the noise is eliminated?
In principle, the minimum such $`\lambda`$ should be used, because a
larger value will only cause further signal distortion.

In order to set $`\lambda`$ so as to reduce Gaussian noise to a desired
level, the effect of the OGS algorithm on pure i.i.d. zero-mean
unit-variance Gaussian noise is investigated. We examine first the case
of group size $`K=1`$, because analytic formulas can be obtained in this
case (OGS being soft thresholding for $`K=1`$).

Let $`y\sim\mathcal{N}(0,1)`$ and define $`x=\soft(y,\,T)`$. Then the
variance of $`x`$ as a function of threshold $`T`$ is given by

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\sigma_{x}^{2}(T)`$ | $`\displaystyle=E[x^{2}]=\int_{|y|>T}\,(\lvert y\rvert-T)^{2}\,p_{y}(y)\,dy`$ |  | (28) |
|  |  | $`\displaystyle=2\,(1+T^{2})\,Q(T)-T\sqrt{\frac{2}{\pi}}\exp\left(-\frac{T^{2}}{2}\right)`$ |  | (29) |

where $`p_{y}(y)`$ is the standard normal pdf $`\mathcal{N}(0,1)`$ and

|  |  |  |
|----|----|----|
|  |
``` math
Q(T):=\frac{1}{\sqrt{2\,\pi}}\,\int_{T}^{\infty}\mathrm{e}^{-\frac{t^{2}}{2}}\,dt=0.5\,\Bigl(1-\erf\Bigl(\frac{T}{\sqrt{2}}\Bigr)\Bigr).
``` |  |

The standard deviation $`\sigma_{x}(T)`$ is illustrated in
Fig. [1](#S3.F1 "Figure 1 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")a
as a function of threshold $`T`$. Since the variance of $`x`$ is unity
here, the $`3\sigma`$ rule suggests setting the threshold to $`T=3`$
which leads to $`\sigma_{x}(3)=0.020`$ according to
([29](#S3.E29 "In 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")).

The graph in
Fig. [1](#S3.F1 "Figure 1 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")a
generalizes the $`3\sigma`$ rule: Given a specified output standard
deviation $`\sigma_{x}`$, the graph shows how to set the threshold $`T`$
in the soft threshold function so as to achieve it, i.e., so that
$`E[\soft(y,T)^{2}]=\sigma_{x}^{2}`$ where $`y\sim\mathcal{N}(0,1)`$.
For example, to reduce the noise standard deviation $`\sigma`$ to one
percent of its value, we solve $`\sigma_{x}(T)=0.01`$ for $`T`$ to
obtain $`T=3.36\sigma`$, a threshold greater than that suggested by the
$`3\sigma`$ rule.

To set the regularization parameter $`\lambda`$ in the OGS algorithm, we
suggest that the same procedure can be followed. However, for OGS there
is no explicit formula such as
([29](#S3.E29 "In 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
relating $`\lambda`$ to $`\sigma_{x}`$. Indeed, in the overlapping group
case, neither is it possible to reduce $`E[x^{2}]`$ to a univariate
integral as in
([28](#S3.E28 "In 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
due to the coupling among the components of $`\mathbf{y}`$, nor is there
an explicit formula for $`\mathbf{x}`$ in terms of $`\mathbf{y}`$, but
only a numerical algorithm.

Figure 1: Standard deviation of standard Gaussian noise
$`\mathcal{N}(0,1)`$ after (a) soft thresholding and (b) overlapping
group shrinkage (OGS) with group size $`3\times 3`$.

Although no explicit analog of
([29](#S3.E29 "In 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is available for OGS, the functional relationship can be found
numerically. Let $`\mathbf{y}`$ be i.i.d. $`\mathcal{N}(0,1)`$ and
define $`\mathbf{x}`$ as the output of the OGS algorithm:
$`\mathbf{x}=\ogs(\mathbf{y};\,\lambda,\,K)`$. The output standard
deviation $`\sigma_{x}`$ can be found by simulation as a function of
$`\lambda`$ for a fixed group size. For example, consider applying the
OGS algorithm to a two-dimensional array $`\mathbf{y}`$ using a group
size of $`3\times 3`$. For this group size, $`\sigma_{x}`$ as a function
of $`\lambda`$ is illustrated in
Fig. [1](#S3.F1 "Figure 1 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")b.
The graph is obtained by generating a large two-dimensional array of
i.i.d. standard normal random variables, applying the OGS algorithm for
a discrete set of $`\lambda`$, and then computing the standard deviation
of the result for each $`\lambda`$. Once this graph is numerically
obtained, it provides a straight forward way to set $`\lambda`$ so as to
reduce the noise to a specified level. For example, to reduce the noise
standard deviation $`\sigma`$ down to one percent of its value, we
should use $`\lambda\approx 0.43\sigma`$ in the OGS algorithm according
to the graph in
Fig. [1](#S3.F1 "Figure 1 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")b.
(Obtaining the value $`\lambda`$ corresponding to a specified
$`\sigma_{x}`$ generally requires an extrapolation between the data

Fig. [1](#S3.F1 "Figure 1 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")b.)
Note that the graph will depend on the group size, so for a different

large enough to reduce the noise to a sufficiently negligible level, yet
no larger so as to avoid unnecessary signal distortion. That is,
suitable values of $`\lambda`$ are somewhat near the knee. Therefore,
due to the sharper knee, the denoising process is more sensitive to

more critical.

Figure 2: Probability density function of zero-mean unit-variance

Although not apparent in
Fig. [1](#S3.F1 "Figure 1 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"),
the soft-thresholding and OGS procedures are quite distinct in their
shrinkage/thresholding behavior. Clearly, if $`\mathbf{y}`$ is
i.i.d. with $`y\sim\mathcal{N}(0,1)`$ and if $`\mathbf{x}`$ is the

contains many zeros. All values $`\lvert y\rvert\leq T`$ are mapped to
zero. The nonlinearity involves *thresholding* in this sense. In
contrast, OGS does not produce any zeros unless $`\lambda`$ is
sufficiently large. This behavior is illustrated in
Fig. [2](#S3.F2 "Figure 2 ‣ 3.1 Shrinkage/Thresholding behavior ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"),
which shows the pdf of $`y`$ after soft thresholding (a) and after OGS
(b, c). Soft thresholding with $`T=1.38`$ produces an output $`x`$ with
$`\sigma_{x}=0.25`$. The pdf of $`x`$, illustrated in
Fig. [2](#S3.F2 "Figure 2 ‣ 3.1 Shrinkage/Thresholding behavior ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")a,
consists of a point mass at the origin of mass $`0.831`$ and the tails
of the Gaussian pdf translated toward the origin. The point mass
represents the zero elements of $`x`$.

Using OGS with group size $`3\times 3`$ and $`\lambda`$ set so that
again $`\sigma_{x}=0.25`$, the output $`x`$ does not contain zeros. The
pdf is illustrated in
Fig. [2](#S3.F2 "Figure 2 ‣ 3.1 Shrinkage/Thresholding behavior ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")b.
The absence of the point mass at the origin reflects the fact that OGS
mapped no values of $`y`$ to zero, i.e. no thresholding. The pdf in
Fig. [2](#S3.F2 "Figure 2 ‣ 3.1 Shrinkage/Thresholding behavior ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")b

When $`\lambda`$ is sufficiently large, then OGS does perform
thresholding, as illustrated in
Fig. [2](#S3.F2 "Figure 2 ‣ 3.1 Shrinkage/Thresholding behavior ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")c.

### 3.2 Complex data

The calculation
([29](#S3.E29 "In 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is for real-valued standard normal $`x`$. For complex-valued Gaussian
data the formula is slightly different:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\sigma_{x}^{2}`$ | $`\displaystyle=\int_{\lvert y\rvert>T}\,\lvert\lvert y\rvert-T\rvert^{2}\,p_{y}(y)\,dy`$ |  | (31) |
|  |  | $`\displaystyle=\exp(-T^{2})-2\sqrt{\pi}\,T\,Q(\sqrt{2}\,T)`$ |  | (32) |

where $`p_{y}(y)`$ is the zero-mean unit-variance complex Gaussian pdf
(standard complex normal), $`\mathcal{CN}(0,1)`$. In the complex case,
([30](#S3.E30 "In 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is modified to

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\sigma_{x}(\lambda)\approx-\frac{\Gamma(\lvert\mathcal{J}\rvert+1/2)}{\Gamma(\lvert\mathcal{J}\rvert)}\,\lambda,\quad\text{for}\;\lambda\approx 0,
``` |  | (33) |

as the degrees of freedom of the chi-distribution is doubled (due to
real and imaginary parts of complex $`y`$). Because complex-valued data
is common (using the Fourier transform, STFT, and in radar and medical
imaging, etc.), it is useful to address the selection of $`\lambda`$ in
the complex case as well as in the real case. Note that
Table [2](#S3.T2 "Table 2 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
does not apply to the complex case.
Table [3](#S3.T3 "Table 3 ‣ 3.1 Shrinkage/Thresholding behavior ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
gives the value of $`\lambda`$ for the complex case, analogous to
Table [2](#S3.T2 "Table 2 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
for the real case.

### 3.3 Remarks

The preceding sections described how the parameter $`\lambda`$ may be
chosen so as to reduce additive white Gaussian noise to a desired level.
However, in many cases the noise is not white. For example, in the
speech denoising example in
Section [4.2](#S4.SS2 "4.2 Speech Denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"),
the OGS algorithm is applied directly in the STFT. However, the STFT is
an overcomplete transform; therefore, the noise in the STFT domain will
not be white, even if it is white in the original signal domain. In the
speech denoising example in
Section [4.2](#S4.SS2 "4.2 Speech Denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
below, this issue is ignored and the algorithm is still effective.
However, in other cases, where the noise is more highly correlated, the
values $`\lambda`$ in
Table [2](#S3.T2 "Table 2 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
and
[3](#S3.T3 "Table 3 ‣ 3.1 Shrinkage/Thresholding behavior ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
may be somewhat inaccurate.

The penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is suitable for stationary noise; however, in many applications, noise
is not stationary. For example, in the problem of denoising speech
corrupted by stationary colored noise, the variance of the noise in the
STFT domain will vary as a function of frequency. In particular, some
noise components may be narrowband and therefore occupy a narrow
time-frequency region. The OGS penalty function and algorithm, as
described in this paper, do not apply to this problem directly. The
penalty function
([4](#S1.E4 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
and the process to select $`\lambda`$ must be appropriately modified.

The OGS algorithm as described above uses the same block size over the
entire signal. In some applications, it may be more appropriate that the
block size varies. For example, in speech denoising, as noted and
developed in \[[72](#bib.bib72)\], it is beneficial that the block size
in the STFT domain varies as a function of frequency (e.g. for higher
temporal resolution at higher frequency). In addition, the
generalization of OGS so as to denoise wavelet coefficients on
tree-structured models as in \[[61](#bib.bib61)\] may be of interest.

## 4 Examples

### 4.1 One-dimensional denoising

As an illustrative example, the OGS algorithm is applied to denoising
the one-dimensional group sparse signal in
Fig. [3](#S4.F3 "Figure 3 ‣ 4.1 One-dimensional denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")a.
The noisy signal in
Fig. [3](#S4.F3 "Figure 3 ‣ 4.1 One-dimensional denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")b
is obtained by adding independent white Gaussian noise with standard
deviation $`\sigma=0.5`$. The dashed line in the figure indicates the
‘$`3\sigma`$’ level. The ‘$`3\sigma`$ rule’ states that nearly all
values of a Gaussian random variable lie within three standard
deviations of the mean (in fact, $`99.7\%`$). Hence, by using
$`3\sigma`$ as a threshold with the soft threshold function, nearly all
the noise will be eliminated as illustrated in
Figure [3](#S4.F3 "Figure 3 ‣ 4.1 One-dimensional denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")c
with threshold $`T=3\sigma=1.5`$. Although the noise is effectively
eliminated, the large-amplitude values of the signal have been
attenuated, which is unavoidable when applying soft thresholding.

Figure 3: Group sparse signal denoising: comparison of soft thresholding
and overlapping group shrinkage (OGS). OGS yields the smaller RMSE.

Even though this choice of threshold value does not minimize the RMSE,
it is a simple and intuitive procedure which can be effective and
practical in certain applications. Moreover, this rule does not depend
on the signal energy (only the noise variance), so it is
straight-forward to apply. Regarding the RMSE, it should be noted that
optimizing the RMSE does not always lead to the most favorable denoising
result in practice. For example, in speech enhancement/denoising, even a
small amount of residual noise will be audible as ‘musical noise’
\[[44](#bib.bib44)\]. (In speech denoising via STFT thresholding, the
RMSE-optimal threshold produces a denoised signal of low perceptual
quality.)

.

[http://www.public.asu.edu/~jye02/Software/SLEP/](http://www.public.asu.edu/~jye02/Software/SLEP/).
We thank the author for verifying the correctness of our usage of SLEP.
We also note that SLEP is a versatile suite of algorithms that can solve
a variety of sparsity-related optimization problems.. The figure shows
the cost function history for the first 150 iterations of each

The run-time for 150 iterations of SLEP, CDAD, ADMM, and OGS are 3,

are much faster than the other two. SLEP is written in C/Mex, so it is
difficult to compare its run-time with the other three algorithms which
are written in MATLAB. The MATLAB implementation of OGS is fast due to
(i) its minimal data indexing, (ii) its minimal memory usage (no
auxiliary/splitting variables), (iii) its computational work is
dominated by convolution which is implemented very efficiently with the
MATLAB built-in conv function.

It should also be noted that ADMM requires that parameters be specified
by the user, which we manually set so as to optimize its convergence
behavior. The algorithm of \[[73](#bib.bib73)\] also calls for
parameters, but the SLEP software provides default values which we used
here. The CDAD and OGS algorithms do not require any user parameters to
be specified. We also note that ADMM and CDAD require 5-times the memory
of OGS, as the group size is $`K=5`$ and the groups are fully
overlapping. In summary, the OGS algorithm has minimal memory
requirements, requires no user specified parameters, and has the most
favorable asymptotic convergence behavior.

We have found that for some problems OGS has a slow convergence during
the initial iterations, compared to the other algorithms. This is
because OGS does not perform explicit thresholding as do the other
algorithms; instead, OGS gradually reduces values toward zero. It may be
appropriate to perform several iterations of another algorithm or
preliminary thresholding to improve initial convergence, and then switch
to OGS. The comparison here uses OGS alone.

Partially overlapping groups. It may be expected that partially

so that the outer sum is over a sub-grid of $`\mathcal{I}`$. We used a

where each group is systematically translated in turn, and we modified
the OGS algorithm accordingly. For each signal, the RMSE-optimal
$`\lambda`$ was numerically found, and the corresponding optimal RMSE
recorded for several values of the noise variance $`\sigma^{2}`$.
Averaging over 100 realizations for each group position and overlap, we
obtain the RMSE values shown in
Table [4](#S4.T4 "Table 4 ‣ 4.1 One-dimensional denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals").
The fully-overlapping case (overlap $`M=4`$) gives the lowest RMSE, as
might be expected. However, the non-overlapping case (overlap $`M=0`$)
does not give the worst RMSE. It turns out that partial overlapping can
yield an inferior RMSE compared to both fully-overlapping and
non-overlapping cases. The reason for this is that, in the partial
overlapping case, some components of $`\mathbf{x}`$ will be a member of
only one group, while other components will be a member of two or more
groups. The more groups a component is a member of, the more strongly it
is penalized. Hence, components of $`\mathbf{x}`$ are non-uniformly
penalized in the partially-overlapping case, and this degrades its
performance when the group structure is not known a priori.

### 4.2 Speech Denoising

This section illustrates the application of overlapping group shrinkage
(OGS) to the problem of speech enhancement (denoising)
\[[44](#bib.bib44)\]. The short-time Fourier transform (STFT) is the
basis of many algorithms for speech enhancement, including classical
spectrum subtraction \[[6](#bib.bib6), [48](#bib.bib48)\], improved
variations thereof using non-Gaussian models \[[47](#bib.bib47),
[35](#bib.bib35)\], and methods based on Markov models
\[[21](#bib.bib21), [26](#bib.bib26), [71](#bib.bib71)\]. A well known
problem arising in many speech enhancement algorithms is that the
residual noise is audible as ‘musical noise’ \[[5](#bib.bib5)\]. Musical
noise may be attributed to isolated noise peaks in the time-frequency
domain that remain after processing. Methods to reduce musical noise
include over estimating the noise variance, imposing a minimum spectral
noise floor \[[5](#bib.bib5)\], and improving the estimation of model
parameters \[[9](#bib.bib9)\]. Due to the musical noise phenomenon, it
is desirable to reduce the noise sufficiently, even if doing so is not
optimal with respect to the RMSE.

To avoid isolated spurious time-frequency noise spikes (to avoid musical
noise), the grouping/clustering behavior of STFT coefficients of speech
waveforms can be taken into account. To this end, a recent algorithm by
Yu et al. \[[72](#bib.bib72)\] for speech/audio enhancement consists of
time-frequency block thresholding. We note that the algorithm of
\[[72](#bib.bib72)\] is based on non-overlapping blocks. Like the
algorithm of \[[72](#bib.bib72)\], the OGS algorithm aims to draw on the
grouping behavior of STFT coefficients so as to improve the overall
denoising result, but it uses a model based on fully overlapping blocks.
Some other recent algorithms exploiting structured time-frequency
sparsity of speech/audio are based on Markov models \[[21](#bib.bib21),
[26](#bib.bib26), [71](#bib.bib71)\].

artifacts are less audible. As for soft-thresholding with $`\lambda`$
selected likewise, musical noise is not audible in the resulting
waveform obtained by applying the inverse STFT.

It was found in \[[72](#bib.bib72)\] that empirical Wiener
post-processing (EWP), introduced in \[[32](#bib.bib32)\], improves the
result of the block thresholding (BT) algorithm. This post-processing,
which is computationally very simple, improves the result of OGS by an
even greater degree than for BT, as measured by SNR improvement. The
Wiener post-processing raises the SNR for BT from 15.35 dB to 15.75 dB,
while it raises the SNR for OGS from 13.77 dB to 15.63 dB. Hence, the
two methods give almost the same SNR after Wiener post-processing. The
substantial SNR improvement in the case of OGS can be explained as
follows: The OGS algorithm has the effect of slightly shrinking
(attenuating) large coefficients which produces a bias and negatively
affects the SNR of the denoised signal. The Wiener post-processing
procedure largely corrects that bias; it has the effect of rescaling
(slightly amplifying) the large coefficients appropriately.

Signal-domain data fidelity. Note that, due to the STFT not being an
orthonormal transform, the noise in the STFT domain is not white, even
when it is white in the signal domain. Therefore, instead of problem
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")),
it is reasonable to solve

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\min_{\mathbf{x}}\;\frac{1}{2}\,\lVert\mathbf{s}-\Phi^{\ast}\mathbf{x}\rVert_{2}^{2}+\lambda\,R(\mathbf{x}),
``` |  | (34) |

which is consistent with the white noise assumption (the data fidelity
term is in the signal domain). Problem
([34](#S4.E34 "In 4.2 Speech Denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
can be solved by proximal methods (e.g. forward-backward splitting
(FBS)) \[[16](#bib.bib16), [15](#bib.bib15), [4](#bib.bib4)\] or ADMM
methods \[[20](#bib.bib20), [27](#bib.bib27), [7](#bib.bib7)\].

We note that the solving
([34](#S4.E34 "In 4.2 Speech Denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
takes more computation than solving
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")).
Formulation
([2](#S1.E2 "In 1 Introduction ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
is, by definition, a single proximal operator (which OGS implements). On
the other hand, solving
([34](#S4.E34 "In 4.2 Speech Denoising ‣ 4 Examples ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals"))
(using ADMM or FBS, etc.) requires the repeated application of the
proximal operator, interlaced with $`\Phi`$ and $`\Phi^{\ast}`$ (forward
and inverse STFTs). In our experiment, solving (34) using ADMM took 5.95
seconds, while solving (2) took 0.25 seconds. We ran 25 iterations of
OGS in each ADMM iteration to implement the proximal operator.

## 5 Conclusion

This paper introduces a computationally efficient algorithm for
denoising signals with group sparsity structure.⁷⁷ 7 MATLAB software to
implement the OGS algorithm and to reproduce the figures in the paper
are online at
[http://eeweb.poly.edu/iselesni/ogs/](http://eeweb.poly.edu/iselesni/ogs/).
In this approach, ‘overlapping group shrinkage’ or OGS, the groups are
fully overlapping and the algorithm is translation-invariant. The method
is based on the minimization of a convex function.

A procedure is described for the selection of the regularization
parameter $`\lambda`$. The procedure is based on attenuating the noise
to a specified level without regard to the statistical properties of the
signal of interest. In this sense, the procedure for setting $`\lambda`$
is not Bayesian; it does not depend on the signal to be estimated. Even
though the described procedure for setting $`\lambda`$ is conceptually
simple, it does not admit the use of explicit formulas for $`\lambda`$
because, in part, the OGS function does not itself have an explicit
formula (it being defined as the solution to a minimization problem).
The procedure to set $`\lambda`$ is based on analyzing the output of OGS
when it is applied to an i.i.d. standard normal signal, and can be
implemented in practice by off-line computation of tables such as
Tables [2](#S3.T2 "Table 2 ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals")
and
[3](#S3.T3 "Table 3 ‣ 3.1 Shrinkage/Thresholding behavior ‣ 3 Gaussian noise and OGS ‣ Translation-Invariant Shrinkage/Thresholding of Group Sparse Signals").
Adopting recent approaches for regularization parameter selection
\[[19](#bib.bib19)\] provides another potential approach to be
investigated.

The paper illustrates the use of overlapping group shrinkage for speech
denoising. The OGS algorithm is applied to the STFT of the noisy signal.
Compared to the block thresholding algorithm \[[72](#bib.bib72)\], the
OGS algorithm gives similar SNR when Wiener post-processing is used.
However, the OGS denoised speech has fewer perceptual artifacts.

Current work includes the investigation of the group-sparsity promoting
penalty function proposed in \[[52](#bib.bib52), [38](#bib.bib38)\],
namely, the derivation of a simple quadratic MM algorithm implementing
the proximal operator, the development of a procedure for setting the
regularization parameter $`\lambda`$ along the lines considered here,
comparison of convergence behavior with other algorithms, and an
evaluation for speech denoising.

## Supplementary Material

MATLAB program for the implementation of overlapping group shrinkage
(1D).

``` ltx_verbatim
function [a, cost] = ogshrink(y, K, lam, Nit)
% [a, cost] = ogshrink(y, K, lam, Nit);
% Overlapping group shrinkage (OGS)
% Minimizes the cost function with respect to a
%
% cost = 0.5 * sum(abs(y - a).^2) + lam * sum(sqrt(conv(abs(a).^2, ones(1,K))));
%
% INPUT
%   y   : 1-D  noisy signal (vector)
%   K   : size of group
%   lam : regularization parameter
%   Nit : number of iterations
%
% OUTPUT
%   a    : output (denoised signal)
%   cost : cost function history

% Po-Yu Chen and Ivan Selesnick
% Polytechnic Institute of New York University
% New York, USA
% March 2012

a = y;                  % initialize
h = ones(1,K);          % for convolution
cost = zeros(1,Nit);
i = (a ~= 0);
for it = 1:Nit
    r = sqrt(conv(abs(a).^2, h));
    cost(it) = 0.5*sum(abs(y - a).^2) + lam * sum(r);
    v = 1 + lam*conv(1./r, h);
    v = v(K:end+1-K);
    % In newer MATLAB, the above 2 lines can be replaced with 1 line:
    % v = 1 + lam*conv(1./r, h, ’valid’);
    a = y./v;
end
````

MATLAB program for the implementation of overlapping group shrinkage
(2D).

```ltx_verbatim
function [a, cost] = ogshrink2(y, K1, K2, lam, Nit)
% [a, cost] = ogshrink2(y, K1, K2, lam, Nit);
% 2D overlapping group shrinkage (OGS)
% Minimizes the cost function with respect to a
%
% cost = 0.5*sum(sum(abs(y - a).^2)) + lam * sum(sqrt(conv(abs(a).^2, ones(K1,K2))));
%
% INPUT
%   y      : 2-D  noisy signal (2D array)
%   K1, K2 : size of group
%   lam    : regularization parameter
%   Nit    : number of iterations
%
% OUTPUT
%   a    : output (denoised signal)
%   cost : cost function history

% Po-Yu Chen and Ivan Selesnick
% Polytechnic Institute of New York University
% New York, USA
% March 2012

a = y;                  % initialize
h1 = ones(K1,1);        % for convolution
h2 = ones(K2,1);        % for convolution
cost = zeros(1,Nit);
for it = 1:Nit
    r = sqrt(conv2(h1, h2, abs(a).^2));
    cost(it) = 0.5*sum(sum(abs(y - a).^2)) + lam * sum(r(:));
    v = 1 + lam*conv2(h1, h2, 1./r);
    v = v(K1:end+1-K1, K2:end+1-K2);
    % In newer MATLAB, the above 2 lines can be replaced with 1 line:
    % v = 1 + lam*conv2(h1, h2, 1./r, ’valid’);
    a = y./v;
end
```
