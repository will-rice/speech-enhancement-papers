# Semi-supervised multichannel speech enhancement with variational autoencoders and non-negative matrix factorization

Simon Leglaive ^(†)^(†)thanks: This work is supported by the ERC
Advanced Grant VHIA \#340113.    Laurent Girin    Radu Horaud

###### Abstract

In this paper we address speaker-independent multichannel speech
enhancement in unknown noisy environments. Our work is based on a
well-established multichannel local Gaussian modeling framework. We
propose to use a neural network for modeling the speech spectro-temporal
content. The parameters of this supervised model are learned using the
framework of variational autoencoders. The noisy recording environment
is supposed to be unknown, so the noise spectro-temporal modeling
remains unsupervised and is based on non-negative matrix factorization
(NMF). We develop a Monte Carlo expectation-maximization algorithm and
we experimentally show that the proposed approach outperforms its
NMF-based counterpart, where speech is modeled using supervised NMF.

###### Index Terms: 

Multichannel speech enhancement, local Gaussian modeling, variational
autoencoders, non-negative matrix factorization, Monte Carlo
expectation-maximization.

## 1 Introduction

Speech enhancement is a classical problem of speech processing which
aims at recovering a clean speech signal from a noisy recording
\[[1](#bib.bib1)\]. In this work we focus on multichannel speech
enhancement in additive noise, with static (non moving) speech and noise
sources. We follow a statistical approach based on a local Gaussian
model of the time-frequency (complex-valued) signal coefficients. This
approach has been very popular for addressing the audio source
separation problem \[[2](#bib.bib2), [3](#bib.bib3), [4](#bib.bib4),
[5](#bib.bib5), [6](#bib.bib6), [7](#bib.bib7), [8](#bib.bib8),
[9](#bib.bib9)\]. In the multichannel case, the covariance matrix of
this model can be structured as the product of a
time-frequency-dependent _variance_, accounting for the spectro-temporal
content of the source signal, and a frequency-dependent _spatial
covariance matrix_ (SCM), accounting for the spatial properties of the
image signal \[[3](#bib.bib3)\]. The variance term was further
structured by means of a non-negative matrix factorization (NMF) model
in \[[2](#bib.bib2), [4](#bib.bib4), [5](#bib.bib5), [6](#bib.bib6)\].
More recently, within this local Gaussian modeling framework based on
SCMs, deep neural networks (DNNs) were investigated as a variance model
\[[8](#bib.bib8)\]. However, in \[[8](#bib.bib8)\] the DNN is not really
integrated in the generative source modeling, it is rather used as an
ad-hoc “deterministic” variance estimator.

For single-channel speech enhancement, DNN-based discriminative
approaches have been successfully investigated for estimating either
time-frequency masks or clean spectrograms from noisy spectrograms
\[[10](#bib.bib10)\]. Very recently, DNN-based generative models, and in
particular variational autoencoders (VAEs) \[[11](#bib.bib11)\], have
been employed for single-channel speech enhancement \[[12](#bib.bib12),
[13](#bib.bib13), [14](#bib.bib14)\]. In \[[13](#bib.bib13)\] we
highlighted conceptual similarities between this approach and a more
conventional generative model based on Itakura-Saito NMF
\[[15](#bib.bib15)\]. We also showed that the VAE-based speech model
outperformed its NMF-based counterpart.

In this paper, we present an extension of \[[13](#bib.bib13)\] to the
multichannel case. The speech and noise models are based on the
above-mentioned multichannel local Gaussian modeling approach. The
speech source spectro-temporal content is further modeled in a
supervised way by means of a DNN, whose parameters are learned using the
VAE framework. We do not assume any prior knowledge on the recording
environment, so the multichannel images of both the speech and the noise
signals include a free SCM model. Moreover the noise source
spectro-temporal model remains unsupervised and is based on NMF. We
propose a Monte Carlo expectation-maximization (MCEM) algorithm
\[[16](#bib.bib16)\] for estimating the model parameters. Experiments
show that our approach outperforms its NMF counterpart
\[[6](#bib.bib6)\], where the speech signal is modeled using supervised
NMF. Note that a similar model for multichannel speech enhancement was
published independently in \[[17](#bib.bib17)\], after we submitted this
paper. It is also combines VAE and NMF within a multichannel local
Gaussian modeling framework, but it relies on a fully Bayesian approach.

## 2 VAE-based speech source model

We work in the short-term Fourier transform (STFT) domain where
$`\mathbb{B}={\{0,...,F-1\}}\times{\{0,...,N-1\}}`$ denotes the set of
time-frequency bins. For $`(f,n)\in\mathbb{B}`$, $`f`$ denotes the
frequency index and $`n`$ the time-frame index. As in
\[[12](#bib.bib12), [13](#bib.bib13)\], independently for every
$`(f,n)\in\mathbb{B}`$, we consider the following generative speech
source model involving a latent random vector
$`\mathbf{z}_{n}\in\mathbb{R}^{L}`$:

|     |                                            |                                                                         |     |     |
| --- | ------------------------------------------ | ----------------------------------------------------------------------- | --- | --- |
|     | $`\displaystyle\mathbf{z}_{n}`$            | $`\displaystyle\sim\mathcal{N}(\mathbf{0},\mathbf{I});`$                |     | (1) |
|     | $`\displaystyle s_{fn}\mid\mathbf{z}_{n}`$ | $`\displaystyle\sim\mathcal{N}_{c}(0,\sigma_{f}^{2}(\mathbf{z}_{n})),`$ |     | (2) |

where $`\mathcal{N}(\boldsymbol{\mu},\boldsymbol{\Sigma})`$ denotes the
multivariate Gaussian distribution for a real-valued random vector,
$`\mathcal{N}_{c}(\mu,\sigma^{2})`$ denotes the univariate complex
proper \[[18](#bib.bib18)\] Gaussian distribution and $`\mathbf{I}`$ is
the identity matrix of appropriate size. As represented in
Fig. [1a](#S2.F1.sf1 "In Figure 1 ‣ 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"),
$`\{\sigma_{f}^{2}:\mathbb{R}^{L}\mapsto\mathbb{R}_{+}\}_{f=0}^{F-1}`$
is a set of non-linear functions provided by a DNN which takes as input
$`\mathbf{z}_{n}\in\mathbb{R}^{L}`$. In the following, we will denote by
$`\boldsymbol{\theta}_{s}`$ the parameters of this _generative network_,
which can be seen as a model of the speech short-term power spectral
density \[[19](#bib.bib19)\].

A key contribution of VAEs is to provide an efficient way of learning
the parameters $`\boldsymbol{\theta}_{s}`$ of such a generative model
\[[11](#bib.bib11)\]. Let
$`\mathbf{s}=\{\mathbf{s}_{n}\in\mathbb{C}^{F}\}_{n=0}^{N-1}`$ be a
training dataset of clean-speech STFT spectra and
$`\mathbf{z}=\{\mathbf{z}_{n}\in\mathbb{R}^{L}\}_{n=0}^{N-1}`$ the set
of associated latent random vectors. Taking ideas from variational
inference, the parameters $`\boldsymbol{\theta}_{s}`$ are estimated by
maximizing a lower bound
$`\mathcal{L}\left(\boldsymbol{\theta}_{s},\boldsymbol{\phi}\right)`$ of
the log-likelihood $`\ln p(\mathbf{s};\boldsymbol{\theta}_{s})`$ defined
by:

|     |     |     |     |
| --- | --- | --- | --- |
|     |

````math
\mathcal{L}\left(\boldsymbol{\theta}_{s},\boldsymbol{\phi}\right)=\mathbb{E}_{q\left(\mathbf{z}\mid\mathbf{s};\boldsymbol{\phi}\right)}\left[\ln p\left(\mathbf{s}\mid\mathbf{z};\boldsymbol{\theta}_{s}\right)\right]-D_{\text{KL}}\left(q\left(\mathbf{z}\mid\mathbf{s};\boldsymbol{\phi}\right)\parallel p(\mathbf{z})\right),
``` |  | (3) |

where $`q\left(\mathbf{z}\mid\mathbf{s};\boldsymbol{\phi}\right)`$
approximates the intractable true posterior distribution
$`p(\mathbf{z}\mid\mathbf{s};\boldsymbol{\theta}_{s})`$, and
$`D_{\text{KL}}(q\parallel p)=\mathbb{E}_{q}[\ln(q/p)]`$ is the
Kullback-Leibler divergence. Independently for all the dimensions
$`l\in\{0,...,L-1\}`$ and all the time frames $`n\in\{0,...,N-1\}`$,
$`q(\mathbf{z}\mid\mathbf{s};\boldsymbol{\phi})`$ is defined by:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
z_{l,n}\mid\mathbf{s}_{n}\sim\mathcal{N}\left(\tilde{\mu}_{l}\left(|\mathbf{s}_{n}|^{\odot 2}\right),\tilde{\sigma}_{l}^{2}\left(|\mathbf{s}_{n}|^{\odot 2}\right)\right),
``` |  | (4) |

where $`z_{l,n}=(\mathbf{z}_{n})_{l}`$ and $`(\cdot)^{\odot\cdot}`$
denotes element-wise exponentiation. As represented in
Fig. [1b](#S2.F1.sf2 "In Figure 1 ‣ 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"),
$`\{\tilde{\mu}_{l}:\mathbb{R}_{+}^{F}\mapsto\mathbb{R}\}_{l=0}^{L-1}`$
and
$`\{\tilde{\sigma}_{l}^{2}:\mathbb{R}_{+}^{F}\mapsto\mathbb{R}_{+}\}_{l=0}^{L-1}`$
are non-linear functions provided by a DNN which takes as input the
speech power spectrum at a given time frame. $`\boldsymbol{\phi}`$
denotes the parameters of this *recognition network*, which also have to
be estimated by maximizing the *variational lower bound* defined in
([3](#S2.E3 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")).
Using
([1](#S2.E1 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")),
([2](#S2.E2 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))
and
([4](#S2.E4 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))
we can develop
([3](#S2.E3 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))
as follows:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathcal{L}\left(\boldsymbol{\theta}_{s},\boldsymbol{\phi}\right)\overset{c}{=}`$ | $`\displaystyle-\sum_{f=0}^{F-1}\sum_{n=0}^{N-1}\mathbb{E}_{q\left(\mathbf{z}_{n}\mid\mathbf{s}_{n};\boldsymbol{\phi}\right)}\left[d_{\text{IS}}\left(\left|s_{fn}\right|^{2};\sigma_{f}^{2}(\mathbf{z}_{n})\right)\right]`$ |  |  |
|  |  | $`\displaystyle\hskip-45.52458pt+\frac{1}{2}\sum_{l=0}^{L-1}\sum_{n=0}^{N-1}\left[\ln\tilde{\sigma}_{l}^{2}\left(\left|\mathbf{s}_{n}\right|^{\odot 2}\right)-\tilde{\mu}_{l}\left(\left|\mathbf{s}_{n}\right|^{\odot 2}\right)^{2}-\tilde{\sigma}_{l}^{2}\left(\left|\mathbf{s}_{n}\right|^{\odot 2}\right)\right],`$ |  | (5) |

where $`\overset{c}{=}`$ denotes equality up to an additive constant and
$`d_{\text{IS}}(x;y)=x/y-\ln(x/y)-1`$ is the Itakura-Saito divergence.
Finally, using the so-called “reparametrization trick”
\[[11](#bib.bib11)\] to approximate the intractable expectation in
([5](#S2.E5 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")),
we obtain an objective function which is differentiable with respect to
both $`\boldsymbol{\theta}_{s}`$ and $`\boldsymbol{\phi}`$ and can be
optimized using gradient-ascent-based algorithms. It is important to
note that the only reason why the recognition network is introduced is
to learn the parameters of the generative network.

## 3 Complete Multichannel Model

In the previous section we have seen how to learn the parameters of the
generative model
([1](#S2.E1 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))-([2](#S2.E2 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")).
This model can then be used as a speech source signal probabilistic
prior for a variety of applications. In this paper we are interested in
multichannel speech enhancement. We now present the model developed for
this task. In the following, $`I`$ denotes the number of microphones,
and probabilistic models are defined independently for all
time-frequency points $`(f,n)\in\mathbb{B}`$.

The multichannel speech signal $`\mathbf{s}_{fn}\in\mathbb{C}^{I}`$ is
modeled as follows:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbf{s}_{fn}\mid\mathbf{z}_{n}`$ | $`\displaystyle\sim\mathcal{N}_{c}\big(\mathbf{0},\boldsymbol{\Sigma}_{\mathbf{s},f}(\mathbf{z}_{n})\big),`$ |  | (6) |

where
$`\boldsymbol{\Sigma}_{\mathbf{s},f}(\mathbf{z}_{n}):=\sigma_{f}^{2}(\mathbf{z}_{n})\mathbf{R}_{\mathbf{s},f}`$.
$`\sigma_{f}^{2}(\cdot)`$ was introduced in
([2](#S2.E2 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))
and models the speech signal power spectral density, $`\mathbf{z}_{n}`$
follows the prior in
([1](#S2.E1 "In 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")),
$`\mathbf{R}_{\mathbf{s},f}\in\mathbb{C}^{I\times I}`$ is the speech
signal spatial covariance matrix (which is Hermitian positive definite)
\[[3](#bib.bib3)\] and
$`\mathcal{N}_{c}(\boldsymbol{\mu},\boldsymbol{\Sigma})`$ is the
multivariate complex proper Gaussian distribution.

The multichannel noise signal $`\mathbf{b}_{fn}\in\mathbb{C}^{I}`$ is
modeled as follows:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbf{b}_{fn}\sim\mathcal{N}_{c}\big(\mathbf{0},\boldsymbol{\Sigma}_{\mathbf{b},fn}\big),
``` |  | (7) |

where
$`\boldsymbol{\Sigma}_{\mathbf{b},fn}:=\left(\mathbf{W}_{b}\mathbf{H}_{b}\right)_{f,n}\mathbf{R}_{\mathbf{b},f}`$,
with
$`\mathbf{W}_{b}=[w_{b,fk}]_{f,k}\in\mathbb{R}_{+}^{F\times K_{b}}`$,
$`\mathbf{H}_{b}=[h_{b,kn}]_{k,n}\in\mathbb{R}_{+}^{K_{b}\times N}`$ and
$`\mathbf{R}_{\mathbf{b},f}\in\mathbb{C}^{I\times I}`$ is the noise SCM
(which is also Hermitian positive definite). The noise spectro-temporal
content is thus modeled by NMF \[[15](#bib.bib15)\], and it remains
unsupervised, i.e. $`\mathbf{W}_{b}`$ and $`\mathbf{H}_{b}`$ will be
estimated from test data (and so will be the speech and noise SCMs).

The noisy mixture signal $`\mathbf{x}_{fn}\in\mathbb{C}^{I}`$ is finally
modeled by:

|     |                                                              |     |     |
|-----|--------------------------------------------------------------|-----|-----|
|     |
       ``` math
       \mathbf{x}_{fn}=\sqrt{g_{n}}\mathbf{s}_{fn}+\mathbf{b}_{fn},
       ```                                                           |     | (8) |

where $`g_{n}\in\mathbb{R}_{+}`$ is a gain parameter whose importance
has been experimentally shown in \[[13](#bib.bib13)\]. We further assume
the independence of the speech and noise signals so that:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbf{x}_{fn}\mid\mathbf{z}_{n}\sim\mathcal{N}_{c}(\mathbf{0},\boldsymbol{\Sigma}_{\mathbf{x},fn}(\mathbf{z}_{n})),
``` |  | (9) |

where
$`\boldsymbol{\Sigma}_{\mathbf{x},fn}(\mathbf{z}_{n}):=g_{n}\boldsymbol{\Sigma}_{\mathbf{s},f}(\mathbf{z}_{n})+\boldsymbol{\Sigma}_{\mathbf{b},fn}`$.

## 4 MCEM algorithm and inference

Let
$`\boldsymbol{\theta}_{u}=\left\{\mathbf{W}_{b},\mathbf{H}_{b},\left\{\mathbf{R}_{\mathbf{s},f},\mathbf{R}_{\mathbf{b},f}\right\}_{f=0}^{F-1},\mathbf{g}=[g_{0},...,g_{N-1}]^{\top}\right\}`$
be the set of model parameters to be estimated. In this section we
develop an MCEM algorithm \[[16](#bib.bib16)\] for this aim. Remember
that the parameters $`\boldsymbol{\theta}_{s}`$ of the speech source
model have been learned during a training phase (see
Section [2](#S2 "2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")).
The set of observed data is denoted by
$`\mathbf{x}=\{\mathbf{x}_{fn}\}_{(f,n)\in\mathbb{B}}`$ while the set of
latent variables is $`\mathbf{z}=\{\mathbf{z}_{n}\}_{n=0}^{N-1}`$. We
will also use $`\mathbf{x}_{n}=\{\mathbf{x}_{fn}\}_{f=0}^{F-1}`$ to
denote all the observations for a given time frame
$`n\in\{0,...,N-1\}`$.

Monte Carlo E-Step.   Let $`\boldsymbol{\theta}_{u}^{\star}`$ denote the
current model parameters. At the E-step of a standard EM algorithm, we
would compute the following conditional expectation of the complete-data
log-likelihood
$`Q(\boldsymbol{\theta}_{u};\boldsymbol{\theta}_{u}^{\star})=\mathbb{E}_{p(\mathbf{z}\mid\mathbf{x};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u}^{\star})}\left[\ln p(\mathbf{x},\mathbf{z};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u})\right]`$.
However, due to the non-linear relationship between the latent variables
and the observations, we cannot compute this expectation in an
analytical form. We thus approximate
$`Q(\boldsymbol{\theta}_{u};\boldsymbol{\theta}_{u}^{\star})`$ using an
empirical average:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\tilde{Q}(\boldsymbol{\theta}_{u};\boldsymbol{\theta}_{u}^{\star})\overset{c}{=}`$ | $`\displaystyle-\frac{1}{R}\sum_{r=1}^{R}\sum_{(f,n)\in\mathbb{B}}\Big[\trace\Big(\mathbf{x}_{fn}\mathbf{x}_{fn}^{H}\left[\boldsymbol{\Sigma}_{\mathbf{x},fn}\big(\mathbf{z}_{n}^{(r)}\big)\right]^{-1}\Big)`$ |  |  |
|  |  | $`\displaystyle+\ln\det\Big(\boldsymbol{\Sigma}_{\mathbf{x},fn}\big(\mathbf{z}_{n}^{(r)}\big)\Big)\Big],`$ |  | (10) |

where $`\cdot^{H}`$ denotes the Hermitian transpose operator,
$`\trace(\cdot)`$ and $`\det(\cdot)`$ denote respectively the trace and
determinant of a matrix, and $`\{\mathbf{z}_{n}^{(r)}\}_{r=1}^{R}`$ is a
sequence of samples asymptotically drawn from the posterior
$`p(\mathbf{z}_{n}\!\mid\!\mathbf{x}_{n};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u}^{\star})`$
using a Markov chain Monte Carlo (MCMC) method. This approach forms the
basis of the MCEM algorithm. Here we use the Metropolis-Hastings
algorithm \[[20](#bib.bib20)\]. Note that unlike the standard EM
algorithm, the likelihood is not guaranteed to increase at each
iteration. Nevertheless, some convergence results in terms of stationary
point of the likelihood can be obtained under suitable conditions
\[[21](#bib.bib21)\].

At the $`m`$-th iteration of the Metropolis-Hastings algorithm and
independently for all $`n\in\{0,...,N-1\}`$, we first draw a sample
$`\tilde{\mathbf{z}}_{n}`$ from a random walk proposal distribution:
$`\mathbf{z}_{n}\mid\mathbf{z}_{n}^{(m-1)}\sim\mathcal{N}(\mathbf{z}_{n}^{(m-1)},\epsilon^{2}\mathbf{I})`$.
Using the symmetry of this proposal distribution, we then compute the
following acceptance probability:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\alpha_{n}`$ | $`\displaystyle=\min\Bigg(1,\frac{p(\tilde{\mathbf{z}}_{n})\prod\nolimits_{f=0}^{F-1}p(\mathbf{x}_{fn}\mid\tilde{\mathbf{z}}_{n};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u}^{\star})}{p\left(\mathbf{z}_{n}^{(m-1)}\right)\prod\nolimits_{f=0}^{F-1}p\left(\mathbf{x}_{fn}\mid\mathbf{z}_{n}^{(m-1)};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u}^{\star}\right)}\Bigg).`$ |  | (11) |

Then we draw $`u_{n}`$ from a uniform distribution
$`\mathcal{U}\left([0,1]\right)`$. If $`u_{n}<\alpha_{n}`$, we accept
the sample and set $`\mathbf{z}_{n}^{(m)}=\tilde{\mathbf{z}}_{n}`$,
otherwise we reject the sample and set
$`\mathbf{z}_{n}^{(m)}=\mathbf{z}_{n}^{(m-1)}`$. We only keep the last
$`R`$ samples for computing
$`\tilde{Q}(\boldsymbol{\theta}_{u};\boldsymbol{\theta}_{u}^{\star})`$,
i.e. we discard the samples drawn during a so-called burn-in period.

M-Step.   At the M-step, we want to minimize the cost function
$`\mathcal{C}(\boldsymbol{\theta}_{u}):=-RQ(\boldsymbol{\theta}_{u};\boldsymbol{\theta}_{u}^{\star})`$
with respect to $`\boldsymbol{\theta}_{u}`$. Similarly to
\[[6](#bib.bib6)\], we adopt a majorization-minimization approach for
solving this optimization problem. From
([10](#S4.E10 "In 4 MCEM algorithm and inference ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")),
([9](#S3.E9 "In 3 Complete Multichannel Model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")),
([7](#S3.E7 "In 3 Complete Multichannel Model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")),
([6](#S3.E6 "In 3 Complete Multichannel Model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))
and using inequalities defined in
Appendix [A](#S1a "A Inequalities ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"),
we can show that
$`\mathcal{C}(\boldsymbol{\theta}_{u})\leq\mathcal{G}(\boldsymbol{\theta}_{u},\boldsymbol{\Phi},\boldsymbol{\Omega})`$
where the majorizing function is defined by:

|  |  |  |  |  |
|----|----|----|----|----|
|  |  | $`\displaystyle\mathcal{G}(\boldsymbol{\theta}_{u},\boldsymbol{\Phi},\boldsymbol{\Omega})=-IFNR`$ |  |  |
|  |  | $`\displaystyle+\sum_{r=1}^{R}\sum_{(f,n)\in\mathbb{B}}\Bigg[\frac{1}{g_{n}\sigma_{f}^{2}\left(\mathbf{z}_{n}^{(r)}\right)}\trace\left(\mathbf{x}_{fn}\mathbf{x}_{fn}^{H}\left(\boldsymbol{\Phi}_{0,fn}^{(r)}\right)^{H}\mathbf{R}_{\mathbf{s},f}^{-1}\boldsymbol{\Phi}_{0,fn}^{(r)}\right)`$ |  |  |
|  |  | $`\displaystyle\hskip 21.33955pt+\sum_{k=1}^{K_{b}}\Bigg(\frac{1}{w_{b,fk}h_{b,kn}}\trace\left(\mathbf{x}_{fn}\mathbf{x}_{fn}^{H}\left(\boldsymbol{\Phi}_{k,fn}^{(r)}\right)^{H}\mathbf{R}_{\mathbf{b},f}^{-1}\boldsymbol{\Phi}_{k,fn}^{(r)}\right)`$ |  |  |
|  |  | $`\displaystyle\hskip 56.9055pt+w_{b,fk}h_{b,kn}\trace\left(\left(\boldsymbol{\Omega}_{fn}^{(r)}\right)^{-1}\mathbf{R}_{\mathbf{b},f}\right)\Bigg)`$ |  |  |
|  |  | $`\displaystyle\hskip 21.33955pt+g_{n}\sigma_{f}^{2}\left(\mathbf{z}_{n}^{(r)}\right)\trace\left(\left(\boldsymbol{\Omega}_{fn}^{(r)}\right)^{-1}\mathbf{R}_{\mathbf{s},f}\right)+\ln\det\left(\boldsymbol{\Omega}_{fn}^{(r)}\right)\Bigg],`$ |  | (12) |

where
$`\boldsymbol{\Phi}=\left\{\boldsymbol{\Phi}_{k,fn}^{(r)}\in\mathbb{C}^{I\times I}\right\}_{r,k,f,n}`$,
$`\boldsymbol{\Omega}=\left\{\boldsymbol{\Omega}_{fn}^{(r)}\in\mathbb{C}^{I\times I}\right\}_{r,f,n}`$
are *auxiliary variables*. This upper bound is tight, i.e.
$`\mathcal{C}(\boldsymbol{\theta}_{u})=\mathcal{G}(\boldsymbol{\theta}_{u},\boldsymbol{\Phi},\boldsymbol{\Omega})`$
if

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\boldsymbol{\Omega}_{fn}^{(r)}`$ | $`\displaystyle=\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right);`$ |  | (13) |
|  | $`\displaystyle\boldsymbol{\Phi}_{0,fn}^{(r)}`$ | $`\displaystyle=g_{n}\sigma_{f}^{2}\left(\mathbf{z}_{n}^{(r)}\right)\mathbf{R}_{\mathbf{s},f}\left[\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right]^{-1};`$ |  | (14) |
|  | $`\displaystyle\boldsymbol{\Phi}_{k,fn}^{(r)}`$ | $`\displaystyle=w_{b,fk}h_{b,kn}\mathbf{R}_{\mathbf{b},f}\left[\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right]^{-1}\forall k\in\{1,...,K_{b}\}.`$ |  | (15) |

Although not jointly convex,
$`\mathcal{G}(\boldsymbol{\theta}_{u},\boldsymbol{\Phi},\boldsymbol{\Omega})`$
is separately convex in each of the individual parameters $`g_{n}`$,
$`w_{b,fk}`$, $`h_{b,kn}`$, $`\mathbf{R}_{\mathbf{s},f}`$ and
$`\mathbf{R}_{\mathbf{b},f}`$. We will therefore update individually and
alternatively those parameters, which corresponds to a (block)
coordinate approach. For one of those parameters, the general procedure
consists in canceling the partial derivative of
$`\mathcal{G}(\boldsymbol{\theta}_{u},\boldsymbol{\Phi},\boldsymbol{\Omega})`$.
In this way we obtain an update that depends on the auxiliary variables.
We then inject in this update the expressions of the auxiliary variables
that make the upper bound tight, which are given by
([13](#S4.E13 "In 4 MCEM algorithm and inference ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))-([15](#S4.E15 "In 4 MCEM algorithm and inference ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")).
For notational convenience, let us first introduce:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathbf{M}_{fn}^{(r)}:=\left(\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right)^{-1}\mathbf{x}_{fn}\mathbf{x}_{fn}^{H}\left(\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right)^{-1}.
``` |  | (16) |

The resulting updates are given as follows:

|  |  |  |  |
|----|----|----|----|

``` math
w_{fk}\leftarrow w_{fk}\left[\frac{\sum\limits_{r=1}^{R}\sum\limits_{n=0}^{N-1}h_{kn}\trace\left[\mathbf{M}_{fn}^{(r)}\mathbf{R}_{\mathbf{b},f}\right]}{\sum\limits_{r=1}^{R}\sum\limits_{n=0}^{N-1}h_{kn}\trace\left[\left(\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right)^{-1}\mathbf{R}_{\mathbf{b},f}\right]}\right]^{1/2};
``` |  | (17) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math
h_{kn}\leftarrow h_{kn}\left[\frac{\sum\limits_{r=1}^{R}\sum\limits_{f=0}^{F-1}w_{fk}\trace\left[\mathbf{M}_{fn}^{(r)}\mathbf{R}_{\mathbf{b},f}\right]}{\sum\limits_{r=1}^{R}\sum\limits_{f=0}^{F-1}w_{fk}\trace\left[\left(\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right)^{-1}\mathbf{R}_{\mathbf{b},f}\right]}\right]^{1/2};
``` |  | (18) |

``` math
\hskip-2.84544ptg_{n}\leftarrow g_{n}\left[\frac{\sum\limits_{r=1}^{R}\sum\limits_{f=0}^{F-1}\sigma_{f}^{2}\left(\mathbf{z}_{n}^{(r)}\right)\trace\left[\mathbf{M}_{fn}^{(r)}\mathbf{R}_{\mathbf{s},f}\right]}{\sum\limits_{r=1}^{R}\sum\limits_{f=0}^{F-1}\sigma_{f}^{2}\left(\mathbf{z}_{n}^{(r)}\right)\trace\left[\left(\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right)^{-1}\mathbf{R}_{\mathbf{s},f}\right]}\right]^{1/2}\hskip-2.84544pt.

Updating the SCMs is done by solving the two following algebraic Riccati
equations (see the procedure in \[[6](#bib.bib6), Appendix I\]):

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbf{R}_{\mathbf{s},f}`$ | $`\displaystyle\left[\sum\limits_{r=1}^{R}\sum\limits_{n=0}^{N-1}g_{n}\sigma_{f}^{2}\left(\mathbf{z}_{n}^{(r)}\right)\left(\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right)^{-1}\right]\mathbf{R}_{\mathbf{s},f}`$ |  |  |
|  |  | $`\displaystyle=\tilde{\mathbf{R}}_{\mathbf{s},f}\left[\sum\limits_{r=1}^{R}\sum\limits_{n=0}^{N-1}g_{n}\sigma_{f}^{2}\left(\mathbf{z}_{n}^{(r)}\right)\mathbf{M}_{fn}^{(r)}\right]\tilde{\mathbf{R}}_{\mathbf{s},f};`$ |  | (20) |

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\mathbf{R}_{\mathbf{b},f}`$ | $`\displaystyle\left[\sum\limits_{r=1}^{R}\sum\limits_{n=0}^{N-1}\left(\mathbf{W}_{b}\mathbf{H}_{b}\right)_{f,n}\left(\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)\right)^{-1}\right]\mathbf{R}_{\mathbf{b},f}`$ |  |  |
|  |  | $`\displaystyle=\tilde{\mathbf{R}}_{\mathbf{b},f}\left[\sum\limits_{r=1}^{R}\sum\limits_{n=0}^{N-1}\left(\mathbf{W}_{b}\mathbf{H}_{b}\right)_{f,n}\mathbf{M}_{fn}^{(r)}\right]\tilde{\mathbf{R}}_{\mathbf{b},f},`$ |  | (21) |

where $`\tilde{\mathbf{R}}_{\mathbf{s},f}`$ and
$`\tilde{\mathbf{R}}_{\mathbf{b},f}`$ denote the SCMs before update.
Note that
$`\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}^{(r)}\right)`$
and therefore $`\mathbf{M}_{fn}^{(r)}`$ should be updated after each one
of the updates
([17](#S4.E17 "In 4 MCEM algorithm and inference ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))-([21](#S4.E21 "In 4 MCEM algorithm and inference ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")).

The criterion $`\mathcal{C}(\boldsymbol{\theta}_{u})`$ suffers from
scale indeterminacies between $`\mathbf{R}_{\mathbf{b},f}`$ and
$`w_{b,fk}`$, and also between $`w_{b,fk}`$ and $`h_{b,kn}`$. At each
iteration of the algorithm, we compensate these indeterminacies by
normalizing the noise SCM so that
$`\trace(\mathbf{R}_{\mathbf{b},f})=1`$ (and scaling the rows of
$`\mathbf{W}_{b}`$ accordingly so that the criterion remains unchanged)
and by normalizing the noise dictionary matrix so that
$`\sum_{f=0}^{F-1}w_{b,fk}=1`$ (and scaling the columns of
$`\mathbf{H}_{b}`$ accordingly).

Speech reconstruction.   Once the unsupervised model parameters are
estimated with the MCEM algorithm, we need to estimate the multichannel
speech signal. For all $`(f,n)\in\mathbb{B}`$, let
$`\tilde{\mathbf{s}}_{fn}=\sqrt{g_{n}}\mathbf{s}_{fn}`$ be the scaled
version of the multichannel speech signal. We estimate this vector
according to its posterior mean:

|  |  |  |  |  |
|----|----|----|----|----|
|  | $`\displaystyle\hat{\tilde{\mathbf{s}}}_{fn}`$ | $`\displaystyle=\mathbb{E}_{p(\tilde{\mathbf{s}}_{fn}\mid\mathbf{x}_{fn};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u})}\left[\tilde{\mathbf{s}}_{fn}\right]`$ |  |  |
|  |  | $`\displaystyle=\mathbb{E}_{p(\mathbf{z}_{n}\mid\mathbf{x}_{n};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u})}\left[\mathbb{E}_{p(\tilde{\mathbf{s}}_{fn}\mid\mathbf{x}_{n},\mathbf{z}_{n};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u})}\left[\tilde{\mathbf{s}}_{fn}\right]\right]`$ |  |  |
|  |  | $`\displaystyle=\mathbb{E}_{p(\mathbf{z}_{n}\mid\mathbf{x}_{n};\boldsymbol{\theta}_{s},\boldsymbol{\theta}_{u})}\left[g_{n}\boldsymbol{\Sigma}_{\mathbf{s},f}(\mathbf{z}_{n})\left(\boldsymbol{\Sigma}_{\mathbf{x},fn}\left(\mathbf{z}_{n}\right)\right)^{-1}\right]\mathbf{x}_{fn}.`$ |  | (22) |

As before,
([22](#S4.E22 "In 4 MCEM algorithm and inference ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization"))
cannot be computed in an analytical form, and it is approximated with
the Metropolis-Hastings algorithm as done in the E-Step. This speech
signal estimate corresponds to a probabilistic multichannel Wiener
filtering averaged over all possible realizations of the latent
variables according to their posterior distribution. Note that the noise
signal can be estimated in a similar way.

## 5 Experiments

Figure 2: Speech enhancement results in terms of SDR, PESQ and STOI
measures. The value of the median is indicated above each boxplot.

Baseline method: We compare our method with its NMF counterpart proposed
in \[[6](#bib.bib6)\]. In this paper, the multichannel speech signal is
modeled by
$`\mathbf{s}_{fn}\sim\mathcal{N}_{c}(0,\left(\mathbf{W}_{s}\mathbf{H}_{s}\right)_{f,n}\mathbf{R}_{\mathbf{s},f}),`$
where $`\mathbf{W}_{s}\in\mathbb{R}_{+}^{F\times K_{s}}`$ and
$`\mathbf{H}_{b}\in\mathbb{R}_{+}^{K_{s}\times N}`$. Compared with the
proposed model defined in
([6](#S3.E6 "In 3 Complete Multichannel Model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")),
the deep-learning based variance model is replaced by a more
conventional NMF model. For this baseline method, we also consider a
supervised speech model by learning the NMF dictionary matrix
$`\mathbf{W}_{s}`$ on the training dataset. The noise model remains
unsupervised and is identical to the one defined in
([7](#S3.E7 "In 3 Complete Multichannel Model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")).

Database: The supervised speech model parameters are learned from the
training set of the TIMIT database \[[22](#bib.bib22)\]. It contains
almost 4 hours of single-channel 16-kHz speech signals, distributed over
462 speakers. For the evaluation of the speech enhancement algorithms,
we created 168 stereophonic noisy mixtures of about 3 seconds each. We
used the monophonic clean speech signals from the TIMIT test set
(speakers and sentences are different than in the training set) and
converted them to stereophonic signals as follows: We uniformly drew a
direction of arrival within \[-90, 90\]° and we delayed one channel with
respect to the other accordingly, assuming a free field propagation. We
then mixed the resulting signals with stereophonic non-stationary noise
signals from the DEMAND database \[[23](#bib.bib23)\] (using channels 1
and 3), at a 0 dB signal-to-noise ratio. The different noisy recording
environments are domestic, nature, office, indoor public spaces, street
and transportation.

Parameters setting: The STFT is computed using a 64-ms sine window
(i.e. $`F=513`$) with 75%-overlap. The proposed and baseline methods are
compared for different settings of the dimension of the latent space
$`L`$ and the rank $`K_{s}`$ of the NMF speech model. For fair
comparison, we set $`L=K_{s}\in\{8,16,32,64,128\}`$. The rank of the
noise model is arbitrarily fixed to $`K_{b}=10`$ for both methods.
Unsupervised NMF parameters are randomly initialized and SCMs are
initialized with identity matrices. For the proposed method,
$`\mathbf{g}`$ is initialized with an all-ones vector. Similarly as in
\[[13](#bib.bib13)\], the Markov chain at the first MCEM iteration is
initialized using the recognition network taking the noisy mixture as
input. Then, at each new E-Step, we use the last sample drawn at the
previous E-Step to initialize the Markov chain. We then run 40
iterations of the Metropolis-Hastings algorithm with
$`\epsilon^{2}=0.01`$, and we discard the first 30 samples as the
burn-in period. The algorithms for the proposed and the baseline methods
are run for 50 iterations.

Neural network: The generative and recognition networks are represented
in
Fig. [1](#S2.F1 "Figure 1 ‣ 2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization").
Each network is feed-forward and fully-connected, with hidden layers
using rectified linear units (ReLUs) \[[24](#bib.bib24)\] and batch
normalization \[[25](#bib.bib25)\]. Output layers use identity
activation functions, so they output real-valued coefficients which is
the reason why we consider logarithm of variances. The preprocessing
layer of the recognition network consists in computing the logarithm of
the input speech power spectra and applying a frequency-wise
standardization (zero-mean and unit-variance) based on the training set.
For jointly learning the parameters of the generative and recognition
networks (see
Section [2](#S2 "2 VAE-based speech source model ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")),
we use the Adam optimizer \[[26](#bib.bib26)\] with a step size of
$`10^{-3}`$, exponential decay rates of $`0.9`$ and $`0.999`$ for the
first and second moment estimates, respectively, and an epsilon of
$`10^{-7}`$ for preventing division by zero. 20% of the TIMIT training
set was kept as a validation set, and early stopping with a patience of
10 epochs was used. Weights were initialized using the uniform
initializer described in \[[27](#bib.bib27)\]. The network architecture
was chosen based on the cost function on the validation set.

Results: The speech enhancement results are presented in
Fig. [2](#S5.F2 "Figure 2 ‣ 5 Experiments ‣ Semi-supervised multichannel speech enhancement withvariational autoencoders and non-negative matrix factorization")
in terms of signal-to-distortion ratio (SDR) \[[28](#bib.bib28)\],
perceptual evaluation of speech quality (PESQ) measure
\[[29](#bib.bib29)\] and short-time objective intelligibility (STOI)
measure \[[30](#bib.bib30)\]. We see that according to all measures, the
proposed method outperforms its NMF-based counterpart. In terms of SDR,
for the best configuration of the two methods ($`L=K_{s}=16`$), we have
a 2.2 dB improvement in median. It is also interesting to observe that
all the performance measures for the baseline method tend to decrease as
$`K_{s}`$ increases (above $`16`$). Increasing the number of parameters
makes the optimization problem more difficult to solve. For the proposed
method, this behaviour also appears (although to a lesser extent) in
terms of SDR only, not in terms PESQ or STOI. Our better performance is
however obtained at the expense of a higher computational time. Due to
the Monte Carlo E-Step, and with the above-mentioned parameters setting,
one iteration of the proposed method is about seven times more expensive
than one iteration of the baseline method. For reproducibility, a Python
implementation of our algorithm and audio examples are available
online.¹¹ 1 https://team.inria.fr/perception/icassp-2019-mvae/

## 6 Conclusion

In this work, we proposed a multichannel speech enhancement method using
a probabilistic speech source model based on variational autoencoders.
The noise model was based on unsupervised NMF, which makes the method
nicely flexible and able to adapt to any (non-stationary) noisy
environment. Experiments demonstrated that the proposed approach
outperforms its NMF-based counterpart. The main limitation of this work
is the increased computational time. In future work, we will replace the
MCEM algorithm by a variational EM algorithm, in order to speed up the
inference.

## A Inequalities

Let $`\boldsymbol{\Sigma}\in\mathbb{C}^{I\times I}`$ be a positive
definite matrix. As
$`\boldsymbol{\Sigma}\mapsto\ln\det\left(\boldsymbol{\Sigma}\right)`$ is
a concave function, it can be majorized at an arbitrary point using a
first-order Taylor expansion:
$`\ln\det\left(\boldsymbol{\Sigma}\right)\leq\ln\det\left(\boldsymbol{\Sigma}_{0}\right)+\trace\left(\boldsymbol{\Sigma}_{0}^{-1}\boldsymbol{\Sigma}\right)-I`$,
where $`\boldsymbol{\Sigma}_{0}\in\mathbb{C}^{I\times I}`$ is a positive
definite matrix \[[31](#bib.bib31), p. 641\]. Moreover, equality holds
if $`\boldsymbol{\Sigma}_{0}=\boldsymbol{\Sigma}`$.

For any positive definite matrix
$`\boldsymbol{\Sigma}\in\mathbb{C}^{I\times I}`$, and any matrix
$`\mathbf{A}\in\mathbb{C}^{I\times I}`$,
$`\boldsymbol{\Sigma}\mapsto\trace\left(\boldsymbol{\Sigma}^{-1}\mathbf{A}\right)`$
is a convex function. Therefore, for any set of Hermitian positive
definite matrices
$`\left\{\boldsymbol{\Sigma}_{k}\in\mathbb{C}^{I\times I}\right\}_{k}`$,
Jensen’s trace inequality gives
$`\trace\left(\left(\sum_{k}\boldsymbol{\Sigma}_{k}\right)^{-1}\mathbf{A}\right)\leq\sum_{k}\trace\left(\boldsymbol{\Sigma}_{k}^{-1}\boldsymbol{\Phi}_{k}\mathbf{A}\boldsymbol{\Phi}_{k}^{H}\right)`$,
where $`\boldsymbol{\Phi}_{k}\in\mathbb{C}^{I\times I}`$ and
$`\sum_{k}\boldsymbol{\Phi}_{k}=\mathbf{I}`$ \[[32](#bib.bib32)\].
Moreover, equality holds if
$`\boldsymbol{\Phi}_{k}=\boldsymbol{\Sigma}_{k}\left(\sum_{k^{\prime}}\boldsymbol{\Sigma}_{k^{\prime}}\right)^{-1}`$.
````
