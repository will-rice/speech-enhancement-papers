###### Abstract

This work focuses on designing low complexity hybrid tensor networks by
considering trade-offs between the model complexity and practical
performance. Firstly, we exploit a low-rank tensor-train deep neural
network (TT-DNN) to build an end-to-end deep learning pipeline, namely
LR-TT-DNN. Secondly, a hybrid model combining LR-TT-DNN with a
convolutional neural network (CNN), which is denoted as CNN+(LR-TT-DNN),
is set up to boost the performance. Instead of randomly assigning large
TT-ranks for TT-DNN, we leverage Riemannian gradient descent to
determine a TT-DNN associated with small TT-ranks. Furthermore,
CNN+(LR-TT-DNN) consists of convolutional layers at the bottom for
feature extraction and several TT layers at the top to solve regression
and classification problems. We separately assess the LR-TT-DNN and
CNN+(LR-TT-DNN) models on speech enhancement and spoken command
recognition tasks. Our empirical evidence demonstrates that the
LR-TT-DNN and CNN+(LR-TT-DNN) models with fewer model parameters can
outperform the TT-DNN and CNN+(TT-DNN) counterparts.

## I Introduction

The state-of-the-art deep learning systems for speech enhancement and
spoken command recognition highly rely on the use of a great amount of
training data and flexible access to centralized cloud
services \[[1](#bib.bib1)\]. This results from the fact that an
over-parameterized deep neural network (DNN) provides a simplified
optimization landscape, which ensures local optimal points that are
close to the global one \[[2](#bib.bib2)\]. Furthermore, a practical
low-complexity speech enhancement system could create many new
applications, such as the mobile-based audio de-noise and speech
recognition platforms run on users’ phones without sending requests to a
remote server where a large deep learning model is set up. In doing so,
a localized low-complexity speech processing system on local devices can
maintain the baseline performance. Thus, it motivates us to design a
low-complexity deep model without losing its capability in terms of
representation and generalization powers \[[3](#bib.bib3),
[4](#bib.bib4), [5](#bib.bib5)\].

The approaches to shrinking deep learning models are divided into two
categories: one refers to the use of new deep learning architectures,
such as convolutional neural network (CNN) with various novel
architectures \[[6](#bib.bib6)\]; another one denotes model pruning and
sparseness methodologies \[[7](#bib.bib7), [8](#bib.bib8)\], where
either theoretically guaranteed pruning method or randomized lottery
ticket hypothesis \[[9](#bib.bib9), [10](#bib.bib10)\] can be used to
attain a tiny machine learning system. In this work, we concentrate on
the first aspect and investigate the deployment of low-rank tensor-train
(TT) networks, where the experiments of speech enhancement and spoken
command recognition (SCR) systems are illustrated to verify the
effectiveness of our proposed models.

TT denotes a tensor decomposition and can characterize the
representation of a chain-like product of three-index core tensors for a
high-order tensor \[[11](#bib.bib11)\]. In doing so, the memory overhead
can be greatly reduced. Compared with other tensor decomposition
methods \[[12](#bib.bib12), [13](#bib.bib13)\] like Tucker decomposition
(TD) \[[14](#bib.bib14)\] and CANDECOMP/PARAFAC
decomposition \[[15](#bib.bib15), [16](#bib.bib16)\], TT is a special
case of a tree-structured tensor network and can be simply scaled to
arbitrarily high-order tensors \[[17](#bib.bib17)\]. Since TT provides a
feed-forward DNN with compact multi-dimensional tensor formats, the TT
representation for the DNN refers to a tensor-train deep neural network
(TT-DNN), where each hidden layer of the DNN can be represented by the
TT formats given randomly initialized TT-ranks. Our empirical study on
TT-DNN for speech enhancement suggests that TT-DNN is capable of
maintaining the DNN baseline performance, and it can significantly
reduce the number of DNN parameters \[[18](#bib.bib18),
[19](#bib.bib19), [20](#bib.bib20)\].

Although TT-DNN can construct a standalone speech
enhancement \[[21](#bib.bib21)\] or SCR system \[[22](#bib.bib22)\],
speech spectral features, like Mel-frequency cepstral coefficients
(MFCC) \[[23](#bib.bib23)\] or Gammatone Features \[[24](#bib.bib24)\],
should be extracted and saved in additional hard disks beforehand. To
realize an end-to-end training pipeline, our previous
work \[[19](#bib.bib19)\] proposed a novel deep hybrid tensor-train
model named CNN+(TT-DNN), which is composed of a CNN at the bottom and a
TT-DNN at the top. The CNN model converts time-series signals into the
corresponding spectral features, and the TT-DNN is used to further deal
with regression or classification problems. The CNN+(TT-DNN) model takes
advantage of the CNN for feature extraction and the TT-DNN for compact
representation of the DNN such that an end-to-end deep hybrid tensor
model can be built.

Moreover, instead of randomly assigning TT-ranks to each hidden layer in
the TT-DNN in our previous work, we can leverage Riemannian optimization
to achieve a low-rank TT-DNN with fewer model parameters from a
well-trained TT-DNN model. In more detail, given a set of large TT-ranks
and a prescribed set of small TT-ranks, we employ the Riemannian
gradient descent (RGD) algorithm to find a new TT-DNN model with the
given small TT-ranks \[[25](#bib.bib25)\] from a well-trained TT-DNN
with the large TT-ranks. The generated low-rank TT-DNN is named
LR-TT-DNN in this work, which approximates the TT-DNN with the large
TT-ranks. Besides, the LR-TT-DNN originates from a well-trained DNN, and
it requires an additional fine-tuning process based on the algorithm of
stochastic gradient descent (SGD) \[[25](#bib.bib25)\]. Furthermore, we
deploy a hybrid model combining LR-TT-DNN with CNN, namely
CNN+(LR-TT-DNN), to implement an end-to-end pipeline and boost the
empirical performance of speech processing \[[19](#bib.bib19)\].

We separately employ speech enhancement and spoken command recognition
experiments to assess the empirical performance of the LR-TT-DNN and
CNN+(LR-TT-DNN) models, and we compare their performance with other TT
models. The speech enhancement is a typical regression problem from a
vector space to another vector space, and SCR represents a
classification problem mapping from a vector space to a finite set of
labels.

## II Related Work and Our Contribution

The technique of tensor-train decomposition (TTD) has been successfully
applied in many machine learning tasks. In particular, Oseledets *et
al.* \[[11](#bib.bib11)\] first proposed the TTN model by employing TTD
on neural networks with fully connected (FC) hidden layers. Then, it was
extended to the CNN \[[26](#bib.bib26)\] and recurrent neural
network \[[27](#bib.bib27)\]. Yu *et al.* \[[28](#bib.bib28)\] employed
the TT model as a sequence-to-sequence dynamic model to forecast
multivariate environmental data, and Izmailov *et
al.* \[[29](#bib.bib29)\] built scalable Gaussian processes with
billions of inducing inputs by utilizing TTD. Another work makes use of
TTN for channel estimation in wireless
communications \[[30](#bib.bib30)\].

Moreover, Sidiropoulos _et al._ investigated tensor factorization models
and set up their relationship with signal processing and machine
learning applications \[[12](#bib.bib12)\]. Bacciu _et al._ summarized
tensor decompositions in deep learning, including TTD, Canonical
Polyadic (CP) decomposition, and TD, and also compared their performance
on neural model compression \[[31](#bib.bib31)\]. Furthermore, our
previous empirical study \[[19](#bib.bib19)\] demonstrated that TD
enables a compressed DNN model, but the model cannot guarantee the DNN
performance. Since TD is a generalization of the CP decomposition (i.e.,
CP can be seen as TD with a super-diagonal core) \[[32](#bib.bib32)\],
this work only considers the comparison between TT and TD in terms of
empirical performance.

Although TTD on neural networks has exhibited excellent performance in
many machine learning tasks, the TT-ranks are randomly assigned to the
TT-DNN such that the model parameters of the TT-DNN can be randomly
initialized followed by a thoroughly training via the SGD algorithm. On
the other hand, a TT-DNN model with small prescribed TT-ranks could be
iteratively found from the TT-DNN with a set of large TT-ranks. More
specifically, this work concentrates on how to generate the LR-TT-DNN
model based on the RGD algorithm. The RGD algorithm is related to the
theory of SGD on Riemannian manifolds developed by \[[25](#bib.bib25)\]
and \[[33](#bib.bib33)\]. Zhang _et al._ proposed a fast stochastic
optimization on Riemannian manifolds \[[34](#bib.bib34)\].

The contribution of this work can be summarized as follows: (1)
leveraging the Riemannian optimization to create an LR-TT-DNN model with
a set of prescribed small TT-ranks and illustrate its performance in
speech enhancement and SCR tasks; (2) setting up hybrid deep tensor
models and illustrates their performance in speech enhancement and SCR
tasks.

````math
### III-B Tensor-Train Decomposition

![Refer to caption](2203.06031v1/ttd1.png)

$`\mathcal{W}_{k}\in\mathbb{R}^{I_{k}\times R_{k-1}\times R_{k}}`$, and

We first define some useful notations: $`\mathbb{R}^{D}`$ denotes a
$`D`$-dimensional real space,
$`\mathbb{R}^{I_{1}\times I_{2}\times\cdot\cdot\cdot I_{K}}`$ is a space
of $`K`$-order tensors,
$`\mathcal{W}\in\mathbb{R}^{I_{1}\times\cdot\cdot\cdot\times I_{K}}`$ is
a $`K`$-dimensional tensor, and
$`\textbf{W}\in\mathbb{R}^{I_{1}\times I_{2}}`$ is an
$`I_{1}\times I_{2}`$ matrix.

As shown in
Figure [1](#S3.F1 "Fig. 1 ‣ III-B Tensor-Train Decomposition ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"),
the technique of TTD assumes that given a set of TT-ranks
$`\{R_{0},R_{1},...,R_{K}\}`$, a $`K`$-order tensor
$`\mathcal{W}\in\mathbb{R}^{I_{1}\times I_{2}\times\cdot\cdot\cdot\times I_{K}}`$
is factorized into the multiplication of 3-order tensors
$`\mathcal{W}_{k}\in\mathbb{R}^{I_{k}\times R_{k-1}\times R_{k}}`$. More
specifically, given a set of indices $`\{i_{1},i_{2},...,i_{K}\}`$,
$`\mathcal{W}(i_{1},i_{2},...,i_{K})`$ is decomposed as
Eq. ([2](#S3.E2 "In III-B Tensor-Train Decomposition ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")).

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{W}(i_{1},i_{2},...,i_{K})=\prod\limits_{k=1}^{K}\mathcal{W}_{k}(i_{k}),
``` |  | (2) |

where $`\forall i_{k}\in I_{k}`$,
$`\mathcal{W}_{k}\in\mathbb{R}^{I_{k}\times R_{k-1}\times R_{k}}`$ and
$`\mathcal{W}_{k}(i_{k})\in\mathbb{R}^{R_{k-1}\times R_{k}}`$. Since
$`R_{0}=R_{K}=1`$, the term $`\prod_{k=1}^{K}\mathcal{W}_{k}(i_{k})`$ is
a scalar value.

One example of TTD is shown as follows: for a $`3`$-order tensor
$`\mathcal{W}(i_{1},i_{2},i_{3})=i_{1}+i_{2}+i_{3}`$, given the set of
TT-ranks $`\{1,2,2,1\}`$, the use of TTD on $`\mathcal{W}`$ outputs
$`3`$ core tensors as
Eq. ([3](#S3.E3 "In III-B Tensor-Train Decomposition ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")).

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{W}_{1}[i_{1}]:=[\begin{matrix}i_{1}&1\end{matrix}],\mathcal{W}_{2}[i_{2}]:=\left[\begin{matrix}1&0\\
i_{2}&1\end{matrix}\right],\mathcal{W}_{3}[i_{3}]:=\left[\begin{matrix}1\\
i_{3}\end{matrix}\right],
``` |  | (3) |

which is derived from
Eq. ([4](#S3.E4 "In III-B Tensor-Train Decomposition ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")).

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{W}(i_{1},i_{2},i_{3})=[\begin{matrix}i_{1}&1\end{matrix}]\left[\begin{matrix}1&0\\
i_{2}&1\end{matrix}\right]\left[\begin{matrix}1\\
i_{3}\end{matrix}\right]=i_{1}+i_{2}+i_{3}.
``` |  | (4) |

### III-C Tensor-Train Deep Neural Network

![Refer to caption](2203.06031v1/ttnn.png)

Fig. 2: An illustration of TTN, which is a tensor of order $`K`$ in TT
format, where the core tensors are of order $`4`$. Given a set of
TT-ranks $`\{R_{0},R_{1},...,R_{K}\}`$, a circle represents a core
tensor
$`\mathcal{W}_{k}\in\mathbb{R}^{I_{k}\times J_{k}\times R_{k-1}\times R_{k}}`$,
and each line is associated with the dimension.

A TTN denotes a TT representation of a feed-forward neural network with
a FC hidden layer. In more detail, for an input tensor
$`\mathcal{X}\in\mathbb{R}^{I_{1}\times I_{2}\times\cdot\cdot\cdot\times I_{K}}`$
and an output tensor
$`\mathcal{Y}\in\mathbb{R}^{J_{1}\times J_{2}\times\cdot\cdot\cdot\times J_{K}}`$,
we get
Eq. ([5](#S3.E5 "In III-C Tensor-Train Deep Neural Network ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"))
as follows:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\begin{split}&\hskip 11.38109pt\mathcal{Y}(j_{1},j_{2},...,j_{K})\\
&=\sum\limits_{i_{1}=1}^{I_{1}}\cdot\cdot\cdot\sum\limits_{i_{K}=1}^{I_{K}}\mathcal{W}((i_{1},j_{1}),...,(i_{K},j_{K}))\cdot\mathcal{X}(i_{1},i_{2},...,i_{K})\\
&=\sum\limits_{i_{1}=1}^{I_{1}}\cdot\cdot\cdot\sum\limits_{i_{K}=1}^{I_{K}}\left(\prod\limits_{k=1}^{K}\mathcal{W}_{k}(i_{k},j_{k})\right)\cdot\prod\limits_{k=1}^{K}\mathcal{X}_{k}(i_{k})\\
&=\prod\limits_{k=1}^{K}\left(\sum\limits_{i_{k}=1}^{I_{K}}\mathcal{W}_{k}(i_{k},j_{k})\cdot\mathcal{X}_{k}(i_{k})\right)\\
&=\prod\limits_{k=1}^{K}\mathcal{Y}_{k}(j_{k}),\end{split}
``` |  | (5) |

where $`\mathcal{X}_{k}(i_{k})\in\mathbb{R}^{R_{k-1}\times R_{k}}`$, and
$`\mathcal{Y}_{k}(j_{k})\in\mathbb{R}^{R_{k-1}\times R_{k}}`$ which
results in a scalar $`\prod_{k=1}^{K}\mathcal{Y}_{k}(j_{k})`$ because of
the ranks $`R_{0}=R_{K}=1`$;
$`\mathcal{W}((i_{1},j_{1}),(i_{2},j_{2}),...,(i_{K},j_{K}))`$ is
closely associated with $`\mathcal{W}(m_{1},m_{2},...,m_{K})`$ as
defined in
Eq. ([2](#S3.E2 "In III-B Tensor-Train Decomposition ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")),
if the indexes $`m_{k}=i_{k}\times j_{k},k\in[K]`$ are set. As shown in
Figure [2](#S3.F2 "Fig. 2 ‣ III-C Tensor-Train Deep Neural Network ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"),
given the TT-ranks $`\{R_{0},R_{1},...,R_{K}\}`$, the multi-dimensional
tensor $`\mathcal{W}`$ is decomposed into the multiplication of
$`4`$-order tensors
$`\mathcal{W}_{k}\in\mathbb{R}^{I_{k}\times J_{k}\times R_{k-1}\times R_{k}}`$.
Besides, to configure a TTN, the ReLU activation is applied to
$`\mathcal{Y}(j_{1},j_{2},...,j_{K})`$ as
Eq. ([6](#S3.E6 "In III-C Tensor-Train Deep Neural Network ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")).

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\begin{split}\mathcal{\hat{Y}}(j_{1},j_{2},...,j_{K})&=\text{ReLU}(\mathcal{Y}(j_{1},j_{2},...,j_{K}))\\
&=\text{ReLU}\left(\prod\limits_{k=1}^{K}\mathcal{Y}_{k}(j_{k})\right).\end{split}
``` |  | (6) |

Then, TTN can be generalized to a deeper architecture and is closely
associated with the TT representation for DNN, namely TT-DNN. Although
the TT-DNN model can be set up and trained from scratch by using the SGD
algorithm,
Figure [3](#S3.F3 "Fig. 3 ‣ III-C Tensor-Train Deep Neural Network ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")
illustrates that a DNN model can be transformed into a TT-DNN structure,
where all FC hidden layers can be represented as the corresponding TT
layers. More specifically, $`\forall k\in[K]`$ and $`\forall l\in[L]`$,
the DNN matrix $`\textbf{W}_{l}\in\mathbb{R}^{J_{l}\times I_{l}}`$ can
be decomposed into $`K`$ core tensors
$`\{\mathcal{W}_{l,1},\mathcal{W}_{l,2},...,\mathcal{W}_{l,K}\}`$, where
$`\mathcal{W}_{l,k}\in\mathbb{R}^{J_{l,k}\times I_{l,k}\times R_{k-1}\times R_{k}}`$,
$`J_{l}=J_{l,1}\times J_{l,2}\times\cdot\cdot\cdot\times J_{l,K}`$ and
$`I_{l}=I_{l,1}\times I_{l,2}\times\cdot\cdot\cdot\times I_{l,K}`$.

![Refer to caption](2203.06031v1/ttn.png)

Fig. 3: Converting DNN into TT-DNN. Each DNN weight $`\textbf{W}_{l}`$
is connected to $`K`$ core tensors
$`\mathcal{W}_{l,1},\mathcal{W}_{l,2},...,\mathcal{W}_{l,K}`$.

The TTD admits a TT-DNN with much fewer number of model parameters than
the related DNN. More specifically, a DNN with
$`\sum_{l=1}^{L}J_{l}I_{l}`$ parameters can be converted to a TT-DNN
with fewer model parameters such as
$`\sum_{l=1}^{L}\sum_{k=1}^{K}J_{l,k}I_{l,k}R_{k-1}R_{k}`$.

## IV Low-Rank Tensor-Train Deep Neural Network

In
Section [III](#S3 "III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"),
given a set of TT-ranks, we can initialize a TT-DNN model associated
with a fixed tensor manifold corresponding to the given TT-ranks, where
the model parameters of the TT-DNN are trained by applying the SGD
algorithm from randomized initialized weights. On the other hand, the
TT-DNN model can also be built according to
Figure [3](#S3.F3 "Fig. 3 ‣ III-C Tensor-Train Deep Neural Network ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing").
From the TT-DNN model in
Figure [3](#S3.F3 "Fig. 3 ‣ III-C Tensor-Train Deep Neural Network ‣ III Preliminaries ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"),
an LR-TT-DNN model can be attained by approximating that TT-DNN model
with a set of large TT-ranks by applying the RGD algorithm which
iteratively finds the TT-DNN with the given small TT-ranks. In this
section, we first introduce the RGD algorithm, and then we theoretically
analyze its convergence and performance.

### IV-A Riemannian Gradient Descent

The objective of Riemannian optimization aims at designing a framework
to solve an optimization problem with the constraint that the solution
belongs to manifolds with a given set of small TT-ranks. The related
Riemannian optimization is formulated as follows: given a TT tensor
$`\mathcal{W}=\{\mathcal{W}_{1},\mathcal{W}_{2},...,\mathcal{W}_{K}\}`$
with a set of prescribed large TT-ranks $`R=\{R_{1},R_{2},...,R_{K}\}`$,
we aim at finding the low-rank TT tensor
$`\hat{\mathcal{W}}=\{\hat{\mathcal{W}}_{1},\hat{\mathcal{W}}_{2},...,\hat{\mathcal{W}}_{K}\}`$
with a set of given small TT-ranks
$`\hat{R}=\{\hat{R}_{1},\hat{R}_{2},...,\hat{R}_{K}\}`$ being close to
$`\mathcal{W}`$, which is mathematically described as
Eq. ([7](#S4.E7 "In IV-A Riemannian Gradient Descent ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")).

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\begin{split}&\hskip 42.67912pt\min\limits_{\mathcal{\hat{W}}}\mathcal{L}(\mathcal{W},\mathcal{\hat{W}})\\
&s.t.,\text{TT-rank}(\mathcal{\hat{W}})=\hat{R},\hskip 2.84526pt\text{TT-rank}(\mathcal{W})=R,\end{split}
``` |  | (7) |

where $`\text{TT-rank}(\mathcal{W})=R`$ means that $`\forall k\in[K]`$,
the $`k`$-th TT-rank of $`\mathcal{W}`$ is equal to $`R_{k}`$.

Besides, the objective function
$`\mathcal{L}(\mathcal{W},\mathcal{\hat{W}})`$ is decomposed as
Eq. ([8](#S4.E8 "In IV-A Riemannian Gradient Descent ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")).

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\mathcal{L}(\mathcal{W},\mathcal{\hat{W}})=\sum\limits_{k=1}^{K}\mathcal{L}(\mathcal{W}_{k},\mathcal{\hat{W}}_{k}).
``` |  | (8) |

![Refer to caption](2203.06031v1/manifold.png)

Fig. 4: An illustration of Riemannian gradient descent.

Moreover, the core tensors with element-wise fixed TT-ranks form a
manifold. The optimization problem as shown in
Eq. ([7](#S4.E7 "In IV-A Riemannian Gradient Descent ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"))
can be solved by utilizing the RGD algorithm, which iteratively finds
the low-rank manifold of $`\mathcal{\hat{W}}`$ from the original
$`\mathcal{W}`$. Given a function $`\mathcal{L}`$ (e.g.,
$`||\cdot||_{F}`$) on a manifold $`\mathcal{M}^{(t)}`$, the updated TT
tensor $`\mathcal{W}^{(t+1)}`$ relies on $`\mathcal{W}^{(t)}`$ as
Eq. ([9](#S4.E9 "In IV-A Riemannian Gradient Descent ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")).

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\begin{split}&\mathcal{W}^{(t+1)}=\mathcal{W}^{(t)}-\eta\nabla\mathcal{L}(\mathcal{W}^{(t)})\\
&\hskip 28.45274pt\mathcal{\hat{W}}^{(t+1)}=\mathcal{R}(\mathcal{W}^{(t+1)}),\end{split}
``` |  | (9) |

where $`\eta`$ is a learning rate, $`\mathcal{R}`$ is a retraction, and
the operator
$`{Proj}_{M^{(t+1)}}(-\eta\nabla\mathcal{L}(\mathcal{W}^{(t)}))`$ in
Figure [4](#S4.F4 "Fig. 4 ‣ IV-A Riemannian Gradient Descent ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")
is a projection from the gradient descent
$`-\eta\nabla\mathcal{L}(\mathcal{W}^{(t)})`$ onto a new tangent space
$`\mathcal{M}^{(t+1)}`$ where $`\mathcal{\hat{W}}^{(t+1)}`$ is a
low-rank TT representation of $`\mathcal{M}^{(t)}`$. The RGD process is
illustrated in
Figure [4](#S4.F4 "Fig. 4 ‣ IV-A Riemannian Gradient Descent ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"):
a TT tensor $`\mathcal{W}^{(t)}`$ starts at the manifold
$`\mathcal{M}^{(t)}`$ and moves to $`\mathcal{W}^{(t+1)}`$ along the
gradient descent $`-\eta\nabla\mathcal{L}(\mathcal{W}^{(t)})`$. The
updated TT tensor $`\mathcal{\hat{W}}^{(t+1)}`$ with lower TT-ranks,
which corresponds to the manifold $`\mathcal{M}^{(t+1)}`$, can be
attained based on the retraction algorithm as shown in
Algorithm [1](#alg1 "Algorithm 1 ‣ IV-A Riemannian Gradient Descent ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing").
The retraction algorithm iteratively attempts to find a new manifold
with lower TT-ranks. The main procedure of the retraction algorithm
refers to a singular value decomposition (SVD) and the low-rank matrices
$`\hat{U}_{k}`$, $`\hat{\Sigma}_{k}`$, and $`\hat{V}_{k}`$ are formed
based on the updated TT rank $`\hat{r}_{k+1}`$. The low-rank matrix
$`\hat{A}_{k}`$ is reshaped into a tensor format as
$`\mathcal{\hat{W}}_{k}`$.

 1. Give the core tensors
$`\{\mathcal{W}_{1},\mathcal{W}_{2},...,\mathcal{W}_{K}\}`$ with
TT-ranks $`r=\{r_{1},r_{2},...,r_{K}\}`$, and a prescribed maximum rank
$`r_{\max}`$.

 2. Initialize a new set of TT-ranks $`\hat{r}=\{1,1,...,1\}`$.

 3. For $`k=1:K`$,

 4.   
$`\textbf{A}_{k}=\text{reshape}\hskip 2.84526pt\mathcal{W}_{k}\in\mathbb{R}^{r_{k}\times n_{k}\times m_{k}\times r_{k+1}}`$
by the       shape $`(r_{k}\cdot n_{k}\cdot m_{k})\times r_{k+1}`$.

 5. For $`k=1:K`$,

 6.   
$`\hat{r}_{k+1}=\min(r_{\max},n_{k}\cdot m_{k}\cdot\hat{r}_{k+1},\frac{r_{k}\cdot r_{k+1}}{\hat{r}_{k+1}})`$.

 7.    $`(U_{k},\Sigma_{k},V_{k})=\text{SVD}(\textbf{A}_{k})`$.

 8.    $`\hat{U}_{k}=U_{k}[:,1:\hat{r}_{k+1}]`$,
$`\hat{\Sigma}_{k}=\Sigma_{k}[1:\hat{r}_{k+1},1:\hat{r}_{k+1}]`$,
   $`\hat{V}_{k}=V_{k}[1:\hat{r}_{k+1},:]`$.

 9.    $`\hat{\textbf{A}}_{k}=\hat{U}_{k}\hat{\Sigma}_{k}\hat{V}_{k}`$.

 10.   $`\mathcal{\hat{W}}_{k}\leftarrow`$ reshape
$`\hat{\textbf{A}}_{k}`$ as
$`\hat{r}_{k}\times n_{k}\times m_{k}\times\hat{r}_{k+1}`$.

 11. Return the updated core tensors
$`\{\mathcal{\hat{W}}_{1},\mathcal{\hat{W}}_{2},...,\mathcal{\hat{W}}_{K}\}`$
   and the updated lower ranks
$`\hat{r}=\{\hat{r}_{0},\hat{r}_{1},...,\hat{r}_{K}\}`$.

### IV-B Convergence Analysis

###### Theorem 1.

Given an $`H`$-smooth and convex loss function $`\mathcal{L}`$, the
algorithm of Riemannian gradient descent as
Eq. ([9](#S4.E9 "In IV-A Riemannian Gradient Descent ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"))

([11](#S4.E11 "In Theorem 1. ‣ IV-B Convergence Analysis ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")).

|  |  |  |  |
|----|----|----|----|
|  |
``` math

``` |  | (10) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math

``` |  | (11) |

where $`\mathcal{W}^{*}`$ and $`\mathcal{W}^{(0)}`$ separately denote
the optimal and initial TT tensors, $`\eta\in(0,\frac{2}{H})`$ denotes
the learning rate, and $`T`$ refers to the number of steps.

###### Proof.

First, we define

|  |  |  |
|----|----|----|
|  |
``` math
\begin{split}\mathcal{T}_{\mathcal{W}^{(t)}}(\mathcal{W}^{(t+1)})&=\mathcal{W}^{(t+1)}-\mathcal{W}^{(t)}=-\eta\cdot\nabla\mathcal{L}(\mathcal{W}^{(t)}).\end{split}
``` |  |

Since $`\mathcal{L}`$ is an $`H`$-smooth function,
Eq. ([12](#S4.E12 "In Proof. ‣ IV-B Convergence Analysis ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"))
stands.

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\begin{split}&\hskip 14.22636pt\mathcal{L}(\mathcal{W}^{(t+1)})\\
&\leq\mathcal{L}(\mathcal{W}^{(t)})+\left\langle\nabla\mathcal{L}(\mathcal{W}^{(t)}),\mathcal{T}_{\mathcal{W}^{(t)}}(\mathcal{W}^{(t+1)})\right\rangle\\
&\hskip 113.81102pt+\frac{H}{2}||\mathcal{T}_{\mathcal{W}^{(t)}}(\mathcal{W}^{(t+1)})||^{2}\\
&\leq\mathcal{L}(\mathcal{W}^{(t)})-\eta||\nabla\mathcal{L}(\mathcal{W}^{(t)})||^{2}+\frac{H\eta^{2}}{2}||\nabla\mathcal{L}(\mathcal{W}^{(t)})||^{2}.\\
\end{split}
``` |  | (12) |

Eq. ([12](#S4.E12 "In Proof. ‣ IV-B Convergence Analysis ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing")),
we obtain
Eq. ([13](#S4.E13 "In Proof. ‣ IV-B Convergence Analysis ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"))
as:

|  |  |  |  |
|----|----|----|----|
|  |
``` math
||\nabla\mathcal{L}(\mathcal{W}^{(t)})||^{2}\leq\frac{2}{\eta(2-H\eta)}\left(\mathcal{L}(\mathcal{W}^{(t)})-\mathcal{L}(\mathcal{W}^{(t+1)})\right).
``` |  | (13) |

Summing up
Eq. ([13](#S4.E13 "In Proof. ‣ IV-B Convergence Analysis ‣ IV Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"))
from $`t=0`$ to $`T-1`$, we obtain

|  |  |  |  |
|----|----|----|----|

``` math
\begin{split}\sum\limits_{t=0}^{T-1}||\nabla\mathcal{L}(\mathcal{W}^{(t)})||^{2}&\leq\frac{2}{\eta(2-H\eta)}\left(\mathcal{L}(\mathcal{W}^{(0)})-\mathcal{L}(\mathcal{W}^{(T)})\right)\\
&\leq\frac{2}{\eta(2-H\eta)}\left(\mathcal{L}(\mathcal{W}^{(0)})-\mathcal{L}(\mathcal{W}^{*})\right),\end{split}
``` |  | (14) |

where $`\mathcal{W}^{*}`$ denotes the optimal tensor such that
$`\mathcal{L}(\mathcal{W}^{*})\leq\mathcal{L}(\mathcal{W}^{(t)}),\forall t\in[0,T-1]`$,
and $`0<\eta<\frac{2}{H}`$ ensures a positive upper bound.

Finally, we separately derive

``` |  | (15) |

|  |  |  |  |
|----|----|----|----|
|  |
``` math

``` |  | (16) |

so that we attain

###### Proposition 1.

which results in an LR-TT-DNN on top of the CNN. The attained LR-TT-DNN

As for the setup of the LR-TT-DNN model in our experiments, the
Frobenius norm $`||\cdot||_{F}`$ is employed, and the learning rate
$`\eta`$ is set to $`1.0`$. The ReLU activation is imposed upon each
LR-TT layer. Since $`||\cdot||_{F}`$ is a smooth and convex function, we
show that $`||\cdot||_{F}`$ is $`\tau`$-gradient dominated (see

###### Corollary 1.

Frobenius norm $`||\cdot||_{F}`$ is a $`1`$-gradient dominated.

###### Proof.

Suppose $`\mathcal{L}(\mathcal{W})=||\mathcal{W}||_{F}`$, and assume
$`\mathcal{W}^{*}`$ as the optimal tensor, so that
Eq. ([19](#S5.E19 "In Proof. ‣ V CNN + Low-Rank Tensor-Train Deep Neural Network ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"))
stands.

|  |  |  |  |
|----|----|----|----|
|  |
``` math
\begin{split}&\hskip 11.38109pt\mathcal{L}(\mathcal{W})-\mathcal{L}(\mathcal{W}^{*})\\
&=||\mathcal{W}||_{F}-||\mathcal{W}^{*}||_{F}\\
&=\frac{\sum\limits_{i_{1},...,i_{K}}(\mathcal{W}(i_{1},...,i_{K}))^{2}-\sum\limits_{i_{1},...,i_{K}}(\mathcal{W}^{*}(i_{1},...,i_{K}))^{2}}{\sqrt{\sum\limits_{i_{1},...,i_{K}}(\mathcal{W}(i_{1},...,i_{K}))^{2}}+\sqrt{\sum\limits_{i_{1},...,i_{K}}(\mathcal{W}^{*}(i_{1},...,i_{K}))^{2}}}\\
&\leq\frac{\sum\limits_{i_{1},...,i_{K}}(\mathcal{W}(i_{1},...,i_{K}))^{2}}{\sqrt{\sum\limits_{i_{1},...,i_{K}}(\mathcal{W}(i_{1},...,i_{K}))^{2}}+\sqrt{\sum\limits_{i_{1},...,i_{K}}(\mathcal{W}^{*}(i_{1},...,i_{K}))^{2}}}\\
&\leq\sqrt{\sum\limits_{i_{1},...,i_{K}}(\mathcal{W}(i_{1},...,i_{K}))^{2}}\\
&=||\nabla\mathcal{L}(\mathcal{W})||_{F}.\end{split}
``` |  | (19) |

## VI Experiments

Our experiments are conducted on speech enhancement and SCR tasks, and
our goal is to assess the performance of the LR-TT-DNN and
CNN+(LR-TT-DNN) models with empirical results. The experiments of speech
enhancement are carried out within a regression framework with deep
models. On the other hand, the SCR task is conducted to evaluate the
classification performance. The goals of our experiments are designed as
follows:

1.  1.
    Examine the benefits of the small TT-ranks in the TT-DNN model.
2.  2.
    Examine the advantages of the hybrid models with the CNN framework
    with and without the small TT-ranks applied.
3.  3.
    Compare the CNN+(TT-DNN) model with the CNN+(LR-TT-DNN) one with the
    same small TT-ranks but with different initialization.

### VI-A Experiments of Speech Enhancement

#### VI-A1 Data profile

The experiments of speech enhancement were conducted on the Edinburgh
noisy speech database \[[35](#bib.bib35)\], where the noisy backgrounds
of the training data are different from the test ones. More
specifically, clean utterances were recorded from $`56`$ speakers
including $`28`$ males and $`28`$ females from different accent regions
of both Scotland and the United States. The clean utterances were
randomly split into $`23075`$ training and $`824`$ test waveforms,
respectively. The noisy training waveforms at $`4`$ SNR levels, (i.e.,
$`15dB`$, $`10dB`$, $`5dB`$, and $`0dB`$), were created by corrupting
clean utterances with $`10`$ noisy types, which resulted in $`40`$
different noisy backgrounds for the training dataset. As for the test
dataset, $`5`$ additional noise types were included to generate the test
dataset. Hence, the noisy conditions for the training dataset were
unmatched with the test one in terms of different noise types at various
SNR values.

#### VI-A2 Experimental setup

In our experiments, we used $`256`$-dimensional normalized log-power
spectral (LPS) \[[36](#bib.bib36)\] features to represent the speech
signals. The LPS features were generated by applying a $`512`$-point
fast Fourier transform (FFT) on a speech segment of $`32`$ms. For each
input frame, $`17`$ adjacent neighboring frames were concatenated into a
high dimensional feature vector, which results in $`17\times 256`$ input
dimensions. The clean reference features associated with the noisy
inputs were assigned to the top layer during the training process, and
the enhanced speech features are taken as the output in the test
process. Besides, the overlap-add method was used to generate the
enhanced speech signals \[[37](#bib.bib37)\]. The criterion of minimum
absolute error (MAE) \[[38](#bib.bib38)\] is taken as the objective loss
function during the training process and it is also used to measure the
test performance on the test dataset. Our previous
work \[[39](#bib.bib39)\] analyzed the performance advantage of MAE over
mean squared error (MSE) \[[40](#bib.bib40)\] and root mean squared
error (RMSE) \[[41](#bib.bib41)\] for DNN-based vector-to-vector
regression. Besides, the Adam optimizer \[[42](#bib.bib42)\] with a
learning rate of $`0.001`$ was used in the training stage.

The following neural architectures were first investigated: DNN, TT-DNN,
and LR-TT-DNN, as shown in
Figure [6](#S6.F6 "Fig. 6 ‣ VI-A2 Experimental setup ‣ VI-A Experiments of Speech Enhancement ‣ VI Experiments ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing").
The DNN owned $`6`$ hidden layers with $`2048`$ units each, and both
TT-DNN and LR-TT-DNN consisted of $`6`$ hidden TT layers. The TT-DNN
model was trained from scratch and the LR-TT-DNN model was built from
that. Moreover, the prescribed large and small TT-ranks were separately
set as $`\{1,12,12,12,1\}`$ and $`\{1,3,4,3,1\}`$, respectively.
Concerning the TT layers in
Figure [6](#S6.F6 "Fig. 6 ‣ VI-A2 Experimental setup ‣ VI-A Experiments of Speech Enhancement ‣ VI Experiments ‣ Exploiting Low-Rank Tensor-Train Deep Neural Networks Based on Riemannian Gradient Descent With Illustrations of Speech Processing"),
each TT layer is set as $`4`$-order tensor format of
$`8\times 4\times 8\times 8`$. Accordingly, each FC hidden layer in the
DNN has $`2048`$ units with the ReLU activation.

Perceptual Evaluation of Speech Quality (PESQ) \[[43](#bib.bib43)\] and
short-time objective intelligibility (STOI) \[[44](#bib.bib44)\] metrics
were adopted to evaluate the speech quality. PESQ, which lies in the
domain from $`-0.5`$ to $`4.5`$, is an indirect assessment and a higher
PESQ score means a better-perceived quality of speech signals.
Similarly, STOI ranges from $`0`$ to $`1`$ and refers to a measurement
of predicting speech intelligibility. The higher the value of the STOI
score is, the better the intelligibility of the speech signal is.

### VI-B Experiments of Spoken Command Recognition

#### VI-B1 Data profile

We conduct our SCR experiments on the Google Speech Command
Dataset \[[45](#bib.bib45)\]. The dataset consists of $`35`$ spoken
commands (e.g., \[‘left’, ‘go’, ‘yes’, ‘down’, ‘up’, ‘on’, ‘right’,
etc.), which results in $`11,165`$ development and $`6,500`$ test
utterances in total. The development dataset is randomly split into two

data are taken for validation. All the audio files are downsampled from
$`16KHz`$ to $`8KHz`$ and they are about $`1`$ second long. A mini-batch
size of $`256`$ is set in the training process, and the speech signals
in a batch are configured as the same length by using zero padding.

## VII Conclusions

This work has presented two novel TT models, namely LR+(TT-DNN) and
CNN+(LR-TT-DNN), whose performance has been measured in speech
enhancement and SCR tasks. We first introduce the RGD algorithm to
generate an LR-TT-DNN model from a well-trained TT-DNN model, and then
we analyze the theoretical performance of the LR-TT-DNN model. Then, we
construct the hybrid model with a CNN to generate the CNN+(LR-TT-DNN)
model. Our experiments on speech enhancement and SCR tasks suggest that
our proposed LR-TT-DNN model with a smaller size achieves better
performance than the DNN and TT-DNN counterparts and that the hybrid
model combining LR-TT-DNN with CNN achieves the best performance.

## Appendix A Definition of a $`\tau`$-gradient dominated function

###### Definition 1.

For a closed convex set $`\mathcal{C}\subset\mathbb{R}^{D}`$ and
function $`f`$ that is differentiable on an open set containing
$`\mathcal{C}`$, we say $`f`$ is $`\tau`$-gradient dominated over
$`\mathcal{C}`$ if there exists a constant $`\tau\geq 0`$ such that
$`\forall\textbf{x},\textbf{x}^{\prime}\in\mathcal{C}`$, we have

|  |  |  |
|----|----|----|
|  |
``` math
\min\limits_{\textbf{x}^{\prime}\in\mathcal{C}}f(\textbf{x}^{\prime})\geq f(\textbf{x})+\min\limits_{\textbf{x}^{\prime}\in\mathcal{C}}\left[\langle\nabla f(\textbf{x}),\textbf{x}^{\prime}-\textbf{x}\rangle+\frac{\tau}{2}\left|\left|\textbf{x}-\textbf{x}^{\prime}\right|\right|_{2}^{2}\right].
``` |  |
````
